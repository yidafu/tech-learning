# AGENTS.md

## 工作区用途

JS/TS 深度学习工作区，非产品代码仓库。用户是**中级前端开发工程师**，目标是从「会用」进阶到「深度理解」JavaScript 与 TypeScript。

## 用户背景与协作方式

- 中文交流；专业术语可保留英文，但解释用中文
- 讲解模式固定三步：**关键概念 → 可运行示例 → 输出预测题**（1–2 道）
- 遇到「背结论」型知识点，优先回到一手规范（ECMA-262、TS Handbook / TypeScript 源码）给依据
- 不要只给结论；用户需要能讲清原理

## 关键文件

- `OUTLINE.md` — 学习大纲（阶段 0–5）。任何学习任务**先对照大纲定位当前进度**，按顺序推进，不跳跃。

## 目录约定

- `notes/stage-N-<topic>/` — 学习笔记按大纲阶段（0–5）分子目录；一主题一文件，kebab-case 命名
- `exercises/<topic>/` — 每个主题一个目录，练习代码放入其中
- 练习文件顶部用注释写明：所属大纲章节、主题、预期输出

## 代码约定

- TypeScript 优先：能用 TS 表达的概念不用纯 JS
- 运行环境假设：Node ≥ 18、ES2022+
- 练习直接运行：`npx tsx <file>`；测试统一用 Vitest（`npx vitest run`）
- TS 示例一律视为 `strict: true`（含 `noUncheckedIndexedAccess` 相关讲解时明确说明）
- 手写实现类练习（Promise/bind/深拷贝等）需附带验证代码或测试

## 里程碑检查

大纲各阶段设有里程碑（手写 Promise、类型体操 10–15 题、工具类型手写）。用户请求新内容前，先确认里程碑是否完成；未完成时提醒而非直接跳过。

## 无构建/无 git

本工作区无构建系统、无 git、无 lint 配置。不要引入脚手架或初始化 git，除非用户明确要求。
