# 软件架构学习大纲

> 目标：从“会写代码”进阶到能独立设计、评估系统架构，理论 + 实践并行。
> 用法：按阶段推进，学到哪一节就勾选对应条目；`[ ]` 未学，`[x]` 已完成。

## 第一阶段：架构思维与设计基础（2~3 周）

> 本阶段导览（分册索引）：[01-第一阶段/01-架构思维与设计基础.md](01-第一阶段/01-架构思维与设计基础.md)

- [x] 1. 认识软件架构
  - 架构的定义与边界：架构 vs 详细设计 vs 代码
  - 架构师的角色、职责与能力模型
  - 架构的本质是权衡（trade-off）：没有银弹
- [x] 2. 代码级设计能力（架构的地基）
  - SOLID 五大原则
  - 常用设计模式（创建型、结构型、行为型中各挑高频的掌握）
  - 高内聚低耦合、关注点分离、DRY / KISS / YAGNI
- [ ] 3. 架构质量属性（非功能需求）
  - 性能、可用性、可扩展性、可维护性、安全性、可测试性
  - 质量属性之间的冲突与取舍

## 第二阶段：经典架构模式（3~4 周）

> 本阶段导览（分册索引）：[02-第二阶段/01-经典架构模式.md](02-第二阶段/01-经典架构模式.md)

- [ ] 1. 单体架构
  - 分层架构（三层 / N 层）
  - 模块化单体（Modular Monolith）
- [ ] 2. 微服务架构
  - 服务拆分的依据与常见误区
  - 服务通信、API 网关、服务治理
  - 微服务的代价：什么时候不该用微服务
  - SOA 历史对照：ESB 与“智能端点、哑管道”
  - 渐进拆分：绞杀者模式与数据拆分
  - 契约管理与向后兼容：Tolerant Reader、消费者驱动契约、共享库边界
- [ ] 3. 事件驱动架构
  - 发布订阅、消息队列
  - 事件溯源（Event Sourcing）与 CQRS
  - 事件形态谱系：事件通知、事件携带状态转移（回查风暴与时点快照）
  - 补充场景：削峰填谷、扇出记账、延迟触发、状态广播、计量事件流
  - 优缺点与取舍：中介者/代理者拓扑、同步与事件的判定、过度事件化反例
- [ ] 4. 其他重要风格
  - 管道-过滤器
  - 六边形架构（端口与适配器）、整洁架构、洋葱架构
  - Serverless
  - 主从模式（主从复制 / master-worker）、代理者模式（Broker）
  - 微内核/插件化架构（扩展点 + 插件注册）
- [ ] 5. 平台化架构：BFF 与中台
  - BFF：按端聚合与裁剪、网关与 BFF 的职责边界
  - 中台：业务/数据/技术中台、能力沉淀的边界判据与退潮教训

## 第三阶段：分布式系统核心技术（4~6 周，重点）

> 本阶段导览（分册索引）：[03-第三阶段/01-分布式系统核心技术.md](03-第三阶段/01-分布式系统核心技术.md)

- [ ] 1. 理论基础
  - CAP、BASE（含 CAP 理论来源与 PACELC 扩展）
  - 一致性模型：强一致 / 最终一致
  - 共识算法：Raft 为主，了解 Paxos
  - Quorum/NWR、Gossip 与 CRDT
- [ ] 2. 远程通信
  - REST vs gRPC vs 消息
  - 序列化协议
- [ ] 3. 数据架构
  - 缓存体系：本地缓存、Redis、缓存穿透 / 击穿 / 雪崩
  - 读写分离、分库分表
  - NoSQL 选型：KV / 文档 / 列族 / 图 / 搜索引擎
- [ ] 4. 分布式事务
  - 2PC、TCC、Saga、本地消息表、最终一致性
- [ ] 5. 高可用与稳定性
  - 限流、熔断、降级、隔离、超时重试
  - 负载均衡与服务发现
  - 异地多活
- [ ] 6. 技术工具档案（补编）
  - 消息队列：Kafka / RocketMQ / RabbitMQ / Pulsar 对比与选型
  - 缓存：Redis / Memcached / Caffeine 与多级缓存
  - 协调与注册中心：ZooKeeper / etcd / Consul / Nacos、分布式锁三载体
