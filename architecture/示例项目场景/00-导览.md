# 示例项目场景

> 用途：讲解任意一节前，从这里挑选合适的示例场景取材。总表给出大纲映射与一句话画像；每个场景的业务画像、核心模块逐一展开（职责/关键实体/典型流程/设计要点与陷阱）、架构挑战映射与取材指引，见本目录下 14 份详情文档（01~12 对应原节一~十二，13、14 为新增场景）。
> 返回：[软件架构学习大纲.md](../软件架构学习大纲.md)

## 使用建议

- **主线演示**：桶装水商城。业务门槛低、领域完整，第二阶段起贯穿使用——同一业务从单体分层逐步改造为模块化单体、DDD、微服务、事件驱动，直观对比各模式得失（演进主线概览见[02 详情](02-桶装水商城.md)）。
- **专题示例**：其余场景按主题取用（见下方映射表），讲到对应小节时切换。
- **对照练习**：工单中心、桶装水商城、MES 是用户熟悉的真实项目，思考题和“你的项目里怎么落地”的讨论优先用它们。

## 场景速览（一句话画像）

**通用贯穿**：

- [订单系统](01-订单系统.md)：C 端电商交易最小完整闭环——商品/购物车/订单/支付/券/履约，教学量级假设全书复用。

**用户真实项目**：

- [桶装水商城](02-桶装水商城.md)：高频低客单 + 周期购订阅 + 押金循环资产 + 自有运力排线；第二阶段起的演进主线。
- [工单中心](03-工单中心.md)：多渠道接入、按类型流转、SLA 时限与催办升级的企业内部服务平台。
- [MES](04-MES制造执行系统.md)：车间执行层——生产工单、报工、设备采集、批次追溯、质量与指令安全；含工控扩展（ISA-95 分层、OT/IT 隔离）。

**经典演示场景**：

- [秒杀/限时抢购](05-秒杀限时抢购.md)：瞬时读洪峰、库存防超卖、削峰填谷、限流保命（读洪峰代表）。
- [即时通讯（IM）](06-即时通讯IM.md)：海量长连接、消息必达且有序、离线补拉、多端同步、写/读扩散。
- [支付与清结算](07-支付与清结算.md)：收款/退款/分账/对账/差错处理，资金零差错与分布式事务的完整舞台。
- [Feed 流内容社区](08-Feed流内容社区.md)：读写 100:1 的持续个性化读、时间线推拉模型、分库分表（与秒杀对照的读系统）。
- [物联网平台](09-物联网平台.md)：海量设备接入、写入型洪峰、不可靠上报治理、时序存储与冷热分层（写洪峰代表）。
- [低代码开发平台](10-低代码开发平台.md)：一切皆元数据、动态字段存储三方案、Schema 版本演化、通用性陷阱与逃生舱；店铺装修 C 端出页——编辑态/运行态分离、发布时静态化直出与动态槽位注入。
- [API 网关](11-API网关.md)：全站流量的策略执行点——插件链、配置热更新、灰度分流、认证卸载与业务渗入防腐。
- [多租户 SaaS 控制平面](12-多租户SaaS控制平面.md)：租户生命周期、套餐计费、双链路计量配额、审计与控制面/数据面分离（与网关成对）。
- [Git 托管平台](13-Git托管平台.md)：代码资产存储（内容寻址、按仓库分片）、PR/MR 评审状态机、CI Runner 拉模式调度、Webhook 至少一次投递；Gitea/GitLab/GitHub 三种架构形态对照。
- [研发 Ops 平台](14-研发Ops平台.md)：应用 × 三环境（开发/预发/生产）模型、容器编排与漂移治理、发布单状态机（灰度/蓝绿/自动回滚）、需求到上线全链路追溯；与 Git 托管平台组成上下游。

## 详情文档统一结构

每份详情文档包含：导语（定位与大纲映射）→ 业务画像（角色、核心业务流、教学量级假设、外部交互）→ 模块总览表 → 核心模块逐一展开（职责 / 关键实体与字段级数据 / 典型流程分步 / 设计要点与典型陷阱，含反例对比；关键处附 Kotlin 骨架片段，均已编译运行验证）→ 架构挑战与知识点映射表 → 与其他场景的联动 → 取材指引（讲到哪些小节用它、可出的思考题方向）。

秒杀、IM、支付、Feed 流、物联网、低代码六个场景的架构深度拆解以第六阶段对应分册为准（详情文档内已交叉链接），详情文档聚焦业务与模块底料。
