# 组合毕业项目施工图：多租户 SaaS 控制台

> 一句话目标：把第二辑九个场景的复刻产物拼装成一个完整的多租户 SaaS 前端底座与四个业务页——启动编排（三份配置并行拉取、失败分级）、权限决定路由与菜单、租户主题与语言包以"基线 + 远端覆盖"注入，之上跑搭建器首页（场景 1）、查询构建器报表页（场景 3）、流程编排页（场景 2）、富文本公告页（场景 6）。本文是**施工图**不是教程：只给阶段计划、每阶段验收清单、场景间集成缝的逐条清单与归属手册——实现细节全部指向已完成的各册。预计工期：3 周（含降级演练与答辩自测）。

## 0. 目标与总验收

- [ ] **启动编排**：登录 → `Promise.allSettled` 并行拉权限/主题/语言包；权限失败（重试 1 次后）阻塞进错误页可重试；主题与语言包失败降级（默认主题/基线包）——三条 Network 面板可见同时发出
- [ ] **分层纪律**：`platform/`（权限/主题/i18n/bootstrap）不认识任何业务；`modules/*` 之间互不 import；删掉任意一个业务模块目录仍可构建启动（dependency-cruiser 门禁）
- [ ] **四个业务页**：搭建器首页（P2）、查询构建器报表页（P3）、流程编排页（P4）、富文本公告页（P5）全部跑在统一底座上——同一套权限/主题/i18n 无一处 if 特判
- [ ] **集成缝零漏**：§3 的集成缝清单逐条验收（权限×物料可见性、主题×图表、i18n×schema label、权限×存量回显等）
- [ ] **答辩三清单**：功能验收清单（图纸 22 第 5 节扩编）、可当场演示的自测表（数字判据）、CI 门禁表三张齐备——图纸第 10 节的自测方法直接沿用

## 2. 分阶段计划（P0–P5）

启动时序（P0/P1 的施工总图，图纸 22 §1 的六段时序直接沿用，此处标注每段归属）：

```text
(1) 登录 → token + tenantId 落地                        —— P0
(2) bootstrap：allSettled 并行拉 [权限(阻塞)/主题(降级)/语言包(降级)]  —— P0/P1
(3) 注入：权限进 AuthProvider；主题写 CSS 变量批；语言包已进 i18n 实例 —— P0/P1
(4) 动态路由生成：单一路由表 × 权限过滤 → Route 树 + 菜单（同一数据源） —— P0
(5) 业务页懒加载：withNs（ns chunk 先于组件 chunk）→ 页面挂载          —— P1/P2-P5
(6) 业务保存：schema/json-logic POST → 后端执行                        —— P3
```

### P0 骨架与权限（3 天）

**输入前提**：07 册完成（权限内核/三件套/三层拦截）；图纸 22 §2.1–2.2 读完。

**任务**：

1. 目录落位：`platform/{auth,theme,i18n,bootstrap}` / `router/` / `modules/` / `app/`（图纸 §3 结构图）；
2. 登录页 + `bootstrap.ts`：`allSettled` 三份配置、失败等级表（权限阻塞/主题降级/语言包降级）、`withTimeout` + 权限重试 1 次；
3. 权限闭环：路由表单一数据源（`meta.permission/titleKey/ns`）→ `generateRoutes/generateMenu/generateBreadcrumb` 三派生 + PermissionGuard + 403 页；
4. 两个 fixture 账号（viewer/editor）+ dev 权限 mock（图纸 §11（一）的 fetchers mock）。

**验收清单**：

- [ ] 未登录访问任意路由重定向 /login
- [ ] 三份配置 Network 同时 pending（无串行瀑布）
- [ ] 屏蔽权限接口 → 错误页非白屏、重试可恢复；屏蔽主题接口 → 默认主题正常进入
- [ ] viewer 账号：菜单无告警入口，URL 直达 403；editor 有 view 无 edit：页面可见、保存禁用带 tooltip
- [ ] `npx depcruise src` 零 error；删 `modules/` 任一目录构建仍通过

### P1 主题与 i18n（3 天）

**输入前提**：08 册、09 册完成；P0 验收全绿。

**任务**：

1. 主题接入 bootstrap：`loadTenantTheme` 三层降级链 → `mergeTokens` → `injectThemeBlock`；首帧内联默认主题关键变量（FOUC 防治）；
2. i18n 接入：基线包 + `applyRemoteLocales` 作为第 ③ 份配置进 `allSettled`（自带降级永不 reject）；`withNs` 路由懒加载合并；语言切换器（策略 B 原子切换）；
3. 主题热更新与语言包热更新共用 BroadcastChannel 通道模式（07 册 M4 的通道思想平移）。

**验收清单**：

- [ ] 主题接口 500 → 默认主题、无品牌色闪烁；语言包接口 500 → 基线文案；语言包返回坏 JSON → 站点正常 + console 校验错误
- [ ] 主题接口返回新租户 → 全站换肤无中间态；暗色切换只动 `data-mode`
- [ ] 切 en-US：菜单/表头/按钮一次原子切换、无刷新、已填表单不丢；`<html lang>` 同步
- [ ] 首次进入子路由：ns chunk 先于页面 chunk，首帧无裸 key
- [ ] 缺失 key：页面显示 key 本身 + 监控接口收到上报

### P2 搭建器首页（4 天）

**输入前提**：场景 1 手册（01 册）完成；P1 验收全绿。

**任务**：把搭建器编辑器挂到 `/pages/builder`（权限 `page:edit`），运行态渲染器挂到租户首页 `/`（`page:read`）；关键接线两条——①物料注册表挂 `defaultPermission`（渲染器 `resolveNodePermission` 三级覆盖：节点显式 > 物料默认 > 无限制）；②页面协议 `title/label` 存 i18n key（渲染期翻译）。

**验收清单**：

- [ ] viewer 打开首页：无权物料区块整棵不渲染（或禁用态，按协议配置）；URL 直达编辑器 403
- [ ] 搭建器保存的页面 schema 发布后，首页运行态渲染一致；撤销/重做全链路可用
- [ ] 首页文案（物料 label）切语言即时切换（schema 只存 key）
- [ ] 编辑器内预览"以某角色视角"：换 checker 后物料可见性与运行态一致
- [ ] 搭建器 chunk 独立懒加载（主包无搭建器代码，visualizer 验证）

### P3 查询构建器报表页（4 天）

**输入前提**：场景 3 手册（03 册）完成；08 册 M4（图表 mirror）完成。

**任务**：`/reports/alert-rule` 页 = 场景 3 查询构建器 + 试运行面板 + echarts 报表卡；关键接线三条——①字段元数据 `FIELD_META` 挂 `permission` + `labelKey`；②报表卡用 `ThemedChart`（token mirror，主题/暗色联动）；③保存链路 `toJsonLogic`（图纸 22 §2.6 纯函数）+ 幽灵节点回显（`fromJsonLogic`，含"被权限过滤的字段 = 对该用户不存在"的统一判定）。

**验收清单**：

- [ ] 增删组/切换 and or/嵌套两层/between 双值/空值不可保存（场景 3 的校验全链路）
- [ ] 保存的规则 JSON 与配置一致（请求体比对）；试运行命中/未命中高亮正确
- [ ] viewer 的字段下拉少一项（字段级权限）；含无权字段的存量规则回显为红色幽灵节点、保存原样回传（不静默丢弃）
- [ ] 切租户主题：报表卡系列色/坐标轴/图例同步换肤；切暗色同样
- [ ] 字段 label 与校验错误消息全部走 i18n（`messageKey + params`，渲染层翻译）

### P4 流程编排页（4 天）

**输入前提**：场景 2 手册（02 册）完成。

**任务**：`/workflows` 页 = 节点图编辑器（reactflow 或 01–03 册自研画布）；关键接线四条——①节点面板控件挂权限（无权节点类型在"添加节点"面板不出现）；②画布样式消费语义 token（节点边框/hover/选中态），适配暗色；③节点/流程名是用户数据不进语言包，面板标签是文案进语言包；④校验错误（无入口节点/孤立节点/环）走 `messageKey` 模式。

**验收清单**：

- [ ] 节点增删/连线/删线/框选/对齐吸附全部可用；一次拖拽 = 一次 undo
- [ ] 无权节点类型不出现在添加面板；流程保存请求体与画布一致
- [ ] 切主题/暗色：节点/连线/minimap 配色跟随（无硬编码色值，stylelint 兜底）
- [ ] 校验错误文案随语言切换（错误结构含 messageKey）
- [ ] 大流程（100+ 节点）平移缩放 ≥ 50fps（视口裁剪/虚拟化生效）

### P5 富文本公告页（3 天）

**输入前提**：06 册完成。

**任务**：`/announcements` 页 = 块编辑器（06 册内核或 TipTap）+ 公告列表；关键接线三条——①编辑器外壳（工具栏/占位文案/斜杠菜单项）全部走 i18n；②编辑区容器样式语义 token（暗色下代码块/引用配色正确）；③公告内容是用户数据：存储原文、原样回显，永不进语言包（文案×数据边界）。

**验收清单**：

- [ ] Enter/Backspace/拖拽移动/slash 面板/markdown 速记按 06 册规格表全绿；中文 IME 全程无打断
- [ ] 切 en-US：工具栏/占位/菜单项切换，已输入的公告内容不变
- [ ] 切暗色：代码块/引用/选区配色正确（编辑器内容区也消费语义 token）
- [ ] 公告编辑有脏状态双通道拦截（路由跳转 + 刷新关闭确认）
- [ ] 富文本 chunk 懒加载；500 块文档打字无卡顿

### （收尾）回归五连 + 答辩自测（2 天）

每阶段结束与最终收尾各跑一遍：

```bash
npm run lint && npm run lint:arch   # eslint + 分层门禁
npx tsc --noEmit                    # 类型化 key / 权限码 / token 名在此编译
npm run check:i18n                  # key 零缺失
npx vitest run                      # 各册纯函数单测（转换器/拆合块/权限内核/OKLCH 色板…）
npm run build && npm run preview    # 演示走生产构建
```

答辩素材直接用图纸 22 第 10 节的自测表方法（30 秒开场白、10 分钟演示脚本、预算回填表）——数字判据的出处（帧预算 16ms、chunk 80KB 等）照抄图纸，不另造标准。

每个业务页（P2–P5）接入底座的**通用十步顺序**——图纸 §9 十步叠加法的推广，每步通过再进下一步，禁止"一次全接上再调"：

1. 路由注册：路由表加 `{path, ns, meta: {titleKey, permission}}`——菜单/守卫/懒加载三件事一次到位（缝 10）；
2. ns 建包：`locales/{lng}/{ns}.json` 建骨架，页面标题/按钮文案全部 key 化（缝 3）；
3. 组件壳：页面容器样式只用语义 token，暗色下先肉眼过一遍（缝 11/14）；
4. 路由级权限：无权账号 URL 直达得 403（缝 6/10）；
5. 按钮级权限：保存/删除类动作挂 `useCan` 禁用 + tooltip（07 册 M2）；
6. 业务内核挂载：该场景手册的核心产物（构建器/节点图/编辑器）接进页面（对应 01/02/03/06 册）；
7. 字段/物料级权限：schema 挂 `permission` 维，渲染层统一过滤或禁用（缝 1/5）；
8. 主题深水区：第三方组件（图表/节点图库）的默认样式映射到语义 token / mirror（缝 2/11/12）；
9. 校验与错误 i18n：错误结构 `messageKey + params`，渲染层翻译（缝 4）；
10. 缝隙回扫：对照 §3 该页涉及的缝逐条打勾 + 本阶段验收清单整表过一遍。

## 3. 场景间集成缝清单（本施工图的核心交付）

每条缝：缝隙描述 → 处理方案 → 归属。凡"不处理会怎样"在图纸 22 §9 出现过的，标注图纸编号。

| # | 缝隙 | 不处理会怎样 | 处理方案（实现锚点） | 归属 |
|---|---|---|---|---|
| 1 | **权限 × 搭建器物料可见性** | 无权物料在租户首页照常渲染（越权 UI）；或物料区对搭建者也隐藏（没法搭页） | 物料 `defaultPermission` + 节点 `permission`（null 显式豁免）三级覆盖，运行态渲染器统一执行；编辑器内物料全可见但标权限角标 | 07 册 M3 + 场景 1 手册（图纸 19 路线 9） |
| 2 | **主题 × 图表** | echarts 图表保持默认蓝，与租户品牌割裂；暗色下白底图表刺眼 | token mirror（只读）+ `theme:changed` 事件 + dispose 按新主题名重建 | 08 册 M4 |
| 3 | **i18n × schema label** | 搭建器/查询构建器的字段标签写死中文，多语言断裂；每语言复制一份 schema 必然漂移 | 协议里 label 一律存 key，渲染期 `t(field.labelKey)`；切语言由订阅自动重渲染 | 09 册（图纸 21 §10.10） |
| 4 | **i18n × 校验消息** | 校验器纯函数拿不到 `t`，错误消息硬编码中文无法翻译 | 校验器产出 `messageKey + params`，渲染层翻译 | P3/P4 任务③（图纸 22 缝隙 2） |
| 5 | **权限 × 存量回显** | viewer 打开含无权字段的存量规则，字段被静默丢弃——保存即悄悄改变告警语义（生产事故级） | 展示过滤与回显判定合一：`isFieldResolvable`（元数据存在 && 未被权限过滤），不通过一律走幽灵节点标红 + 原样回传 | 07 册 M3 + P3 任务③（图纸 22 缝隙 3） |
| 6 | **权限 × 启动编排** | 主题接口抖动把权限正常的用户挡在门外；或权限拿不到时放行默认集（越权） | `allSettled` + 失败等级表：权限阻塞（重试 1 次 → 错误页）、主题/语言包降级 | P0 任务 2（图纸 22 §2.2） |
| 7 | **主题 × FOUC × 启动** | 首帧默认蓝闪一下再变租户绿；或主题未决时渲染真实内容 | bootstrap 内"先应用再渲染"+ 骨架屏双保险；首屏内联默认主题关键变量 | P1 任务 1（图纸 22 §2.2/2.3） |
| 8 | **租户切换 × 各类缓存** | A 租户的远端 options 出现在 B 租户下拉（数据越权）；旧租户主题/文案残留 | 缓存键全部带租户维度（`tenant:{id}:...`）；切租户 = 清租户层缓存 + 重新 bootstrap（语言包三层架构的"摘层重算"） | 09 册 + 图纸 21 §10.11 |

## 4. 目录落位与 PR 切分

```text
src/
  platform/            # 平台层：与业务无关，可整体复用到任何 SaaS
    auth/              #   07 册：kernel / AuthProvider / Protected / 字段级
    theme/             #   08 册：types / oklch / mergeTokens / inject / tokenMirror
    i18n/              #   09 册：index / lazyLoad / applyRemote / missingReport / pseudoLoc
    bootstrap/         #   本施工图 P0：bootstrap.ts / fetchers.ts（唯一允许 fetch 的地方）
  router/              # 装配层：routes.ts（唯一数据源）/ AppRouter.tsx
  modules/             # 业务层：按领域切，互不 import
    dashboard/  builder/        # P2（01 册产物）
    reports/                    # P3（03 册产物：构建器 + 试运行 + 图表）
    workflows/                  # P4（02 册产物）
    announcements/              # P5（06 册产物）
  pages/               # 通用页：登录 / 403 / 错误页
  components/          # 跨业务展示组件（PageSkeleton 等，只消费语义 token）
  app/                 # 入口：App.tsx（bootstrap 门禁三态装配）/ main.tsx
```

PR 切分建议（每阶段 2~3 个 PR，review 粒度可控）：P0 = [目录+登录+bootstrap] + [路由三派生+403]；P1 = [主题链路] + [i18n 双包+切换器]；P2–P5 每页一个 PR（按十步顺序分两个 commit：底座接线 / 业务内核挂载）；收尾 = [降级演练+监控埋点] + [CI 门禁表]。两条目录纪律（modules 互不引用、platform 不 import 业务）由 depcruise 硬门禁，PR 模板里再放一遍人工确认项。

## 5. 场景 4/5 的挂载点（可选扩展，P5 后）

九场景全拼的完整性检查——场景 4 与 5 不在 P0–P5 主线上，挂载点如下，时间盒富余时作为扩展阶段：

- **场景 4（JSON Schema 编辑器，04 册）→ 租户自定义字段管理**：租户管理员在 `/settings/fields` 用 schema 编辑器定义自定义字段（导出的 schema 驱动 P3 查询构建器的字段元数据与 P2 运行态表单）——编辑器导出 = 字段注册的输入，`$ref` 用于字段模板复用。
- **场景 5（无限画布白板，05 册）→ 架构图页 / 流程编排画布底座**：`/workflows` 若用自研画布（05 册的 camera/命中/框选）替代 reactflow，则场景 5 整册下沉为 P4 的画布内核；或独立挂 `/sketch` 白板页（权限 `sketch:edit`）。

挂载验收各一条：schema 编辑器导出的字段 schema 能被 P3 的 FIELD_META 消费（端到端一条用例）；白板页在 10 万元素 fixture 下平移 ≥ 50fps。

## 6. 降级与时间盒（对齐图纸 §11）

时间不够时的砍序（从上往下砍，砍到三条底线为止）：

| 优先砍 | 理由 |
|---|---|
| P4 流程编排页整页（换占位路由） | 与底座耦合最浅，砍它不伤任何骨架 |
| 场景 4/5 挂载点（§4） | 本就是可选扩展 |
| 暗色模式矩阵回归（保留正交注入，砍视觉回归） | 正交设计的验证收益低于成本，先保亮色 |
| P5 的 markdown 速记与脏拦截 | 编辑器核心行为（拆合块/IME）保留即可 |
| ——到底线—— | 再往下碰三条底线，不许砍 |

三条底线（图纸 §11（二）原文对齐，本项目的具体化）：

1. **数据流单向**：权限/主题/文案各一个 Provider，`fetch('/api/` 只出现在 `platform/bootstrap/fetchers.ts`——PR 里出现第二处即打回；
2. **失败分级不倒置**：权限阻塞、主题文案降级——改动失败等级表的 PR 必须写理由并同步验收项；
3. **契约与数据不丢**：`toJsonLogic/fromJsonLogic` 带往返单测；幽灵节点原样回传；保存链路不允许出现"过滤/清洗幽灵节点"的代码。

每砍一项登记一条 issue（降级模板：为什么降 / 绝不可降的部分 / 恢复时机 / 证据）——被动被翻出的缺口扣分，主动声明的取舍加分。

## 7. 坑与调试（拼装期高发，按阶段排序）

1. **P0：三份配置写成串行 await**（症状：启动耗时 = 三者之和，降级语义全乱）。这是图纸 §11 滑坡形态 1——最先修。
2. **P0：权限 mock 全给 admin**（症状：权限演示全部失真，最后一天收不回来）。第一天就建 viewer/editor fixture，权限码 mock 进 fetchers。
3. **P1：切主题后某页不跟随**（症状：初始化时把 token 值快照进 JS 常量/内联样式）。全局 grep `getComputedStyle` 调用点，收敛到 mirror。
4. **P2/P3：业务页绕过平台 API 直接 fetch**（症状：降级与热更新失效）。PR 红线：`fetch('/api/` 只允许出现在 bootstrap/fetchers。
5. **P3：幽灵节点被"顺手清洗"**（症状：viewer 保存后无权字段的条件消失，规则语义被悄悄改变）。图纸三底线之一：字段级权限只意味着"不可编辑"，不是"从世界上消失"。
6. **P4：节点图库的默认样式硬编码色值**（症状：换租户/暗色后节点图独树一帜）。接入第一件事就是把库的默认主题映射到语义 token。
7. **P5：编辑器内容进语言包**（症状：翻译平台收到一堆公告正文）。文案×数据边界判据（缝 9）贴在 PR 模板。
8. **通用：集成缝"一次全接再调"**（症状：出问题不知道是哪条缝）。按 §2 每阶段十步以内的顺序接缝，每接一条跑一次对应验收——图纸 §9 十步叠加顺序的方法直接沿用。
