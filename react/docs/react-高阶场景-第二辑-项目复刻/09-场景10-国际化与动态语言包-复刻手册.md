# 场景 10 复刻手册：国际化与动态语言包

> 一句话目标：从零复刻一套"静态基线 + 远端覆盖"双包架构的 i18n 体系——ICU MessageFormat 基线（复数/性别/嵌套的完整处理）、namespace 按需加载（路由级懒加载）、Intl 全家桶（日期/数字/货币/时区）、RTL 布局镜像（逻辑属性 + 方向性图标 + JS 侧方向上下文）、翻译工作流（key 提取、缺失检测、伪翻译测试）。动态语言包是**架构问题**不是工程问题：远端包一定会坏，架构要保证坏的时候站点不倒。预计工期：1 周。前置要求：图纸 21 号文件 10.1–10.4 通读；react-i18next 基本用法。

## 0. 目标与总验收

- [ ] **ICU 基线**：`{count, plural, =0 {无订单} other {# 条订单}}` 在 zh/en 两语言下渲染正确；en 的 one/other 分支、`count=21` 落回 one 类别的坑用例通过；select（性别）与"性别 × 复数"嵌套用例通过
- [ ] **namespace 加载**：`lazyLoadNamespace(lng, ns)` 幂等（并发调用只发一次请求）；路由级懒加载与组件 chunk 合并（先 ns 后组件，首帧无裸 key）；语言切换时为本会话用过的 ns 补加载（原子切换，无 Suspense 闪断）
- [ ] **双包合并**：远端覆盖包拉取（超时 5s）→ 结构校验（顶层形状/叶子全 string/禁原型污染键）→ 逐语言逐 ns 深合并（远端优先）→ 注入 + `emit('languageChanged')` 刷新；fetch 失败 warn 用基线、校验失败 error 丢包用基线、单语言失败不影响其他语言
- [ ] **Intl 全家桶**：`useFormatters` hook（date/currency/relative，显式 locale + timeZone）；模块级缓存（长表格 1000 行不重复构造 Intl 实例）；时区纪律——存储传输全 UTC（带 Z），展示才换算
- [ ] **RTL 镜像**：`dirFor(lng)` 同步 `<html dir>`；CSS 全量迁移逻辑属性（对照表逐项过）；方向性图标 `scaleX(-1)` 镜像清单；JS 侧 `useDirection` 提供方向感知的位移符号；混排用户内容用 `<bdi>`
- [ ] **翻译工作流**：`check-i18n-keys` 脚本双向 diff（已用未定义=缺失阻断 CI、已定义未用=冗余警告）；TS 类型化 key（typo 编译期红线）；伪语言 `zz-PSEUDO`（重音化 + 40% 拉长）可切换且按钮溢出肉眼可见
- [ ] **缺失监控**：`parseMissingKeyHandler` 上报缺失 key（批处理 + sendBeacon），删掉基线一个 key 页面显示 key 本身且监控接口收到记录

## 2. 里程碑切分

### M1 ICU MessageFormat 基线（约 1 天）

**目标**：i18next + `i18next-icu` 接入，复数/性别/嵌套三类语法全通。

**做什么**：init（`escapeValue: false`、`fallbackLng: 'zh-CN'`、`parseMissingKeyHandler` 先返回 key 本身）；基线包 `locales/{lng}/{ns}.json`；复数（`=0` 精确匹配 + `other`）、selectordinal（en 的 1st/2nd/3rd/21st）、select（male/female/other）、嵌套（性别分支里嵌复数）各写一组 key + 用例。

**验收**：

count 取 0/1/2/5/21 的 en 复数快照（21 → "21st/21 items"落 one 类别的坑用例必写）；ICU 语法错（`other{#}` 少空格）在冒烟测试里被 `parse` 抓住。

### M2 动态语言包加载：namespace 按需（约 1.5 天）

**目标**：ns 级代码分包 + 路由级懒加载 + 语言切换原子性。

**做什么**：§4.1 加载器（`touchedNamespaces` 记忆 + 幂等 in-flight 处理）；路由懒加载合并（模式 A：`lazy(async () => { await ensureNs; return import(页面) })`）；`LanguageSwitcher` 走策略 B——先 `ensureLanguageLoaded(next)` 再 `changeLanguage`，期间旧文案保持可交互。

**验收**：首次进入子路由，Network 面板 ns chunk 与页面 chunk 依次加载、首帧无裸 key；切语言按钮 pending ≤ 300ms 且无骨架闪断；切换后已填写的表单状态不丢；并发调用 `lazyLoadNamespace` 同一 ns 只有一次网络请求。

### M3 复数/性别/嵌套的完整处理 + 双包合并（约 2 天）

**目标**：远端覆盖包安全地叠到基线之上（图纸 10.4 的核心）。

**做什么**：`deepMerge`（远端优先、数组整体替换）、`validateNamespacePack/validateRemotePayload`（禁 `__proto__/constructor/prototype`）、`applyRemoteLocales`（fetch 超时 → 校验 → 逐语言合并注入 → emit 刷新）——三段代码图纸已给全，本册施工重点是把**失败等级**测出来：fetch 失败 warn、校验失败 error、语言粒度隔离。

**验收**：mock 远端包改一条文案 → 不刷新页面文案更新；mock 坏 JSON / 叶子非 string / 含 `__proto__` 键 → 三种坏包各自被拦、站点用基线、console 有定位；en 包坏 zh 包好 → 只有 zh 的覆盖生效；`addResourceBundle` 后不 emit 的组件不刷新（反向验证 emit 必要性）。

### M4 日期数字货币本地化：Intl 全家桶（约 1 天）

**目标**：`useFormatters` + 模块级缓存 + 时区纪律。

**做什么**：图纸 10.6 的 hook 原样落；`formatCache.ts`（模块级 `Map<key, Intl.DateTimeFormat>`，key 覆盖全部影响输出的选项）；dayjs utc/timezone 插件处理"用户时区选了 09:00 → 转 UTC 发后端"与"按天筛选先算用户时区边界"。

**验收**：同一时刻三时区渲染断言（上海 20:00 / 纽约 07:00 / 柏林 13:00）；`ja-JP` 货币格式无小数位；1000 行表格日期列构造次数 = 样式数（非行数）；全项目 grep 无裸 `toLocaleDateString()` 调用。

### M5 RTL 布局镜像（约 1.5 天）

**目标**：加一门 RTL 语言（ar-SA），布局整体镜像无破绽。

**做什么**：§4.2 RTL 方案全套（`<html dir>` 同步、CSS 逻辑属性迁移、方向性图标镜像、`useDirection`、`<bdi>` 混排）；stylelint 禁物理方向属性（新代码）；翻转子菜单展开方向、面包屑分隔符、进度条方向三处典型 UI 验证。

## 4. 核心代码摘录

### 4.1 namespace 加载器（M2）

```ts
// src/i18n/lazyLoad.ts —— ns 级懒加载：幂等 + 会话记忆 + 语言切换补齐
import i18n from './index';
import type { AppLanguage } from './types';

/** 本会话用过的 ns：语言切换时为新语言补齐同一批（策略 B 原子切换的前提） */
const touchedNamespaces = new Set<string>(['common']);

/** in-flight 去重：并发调用同一 (lng, ns) 共享一个 Promise——只发一次请求 */
const inflight = new Map<string, Promise<void>>();

/** 语言 → ns → 动态 import 映射（构建器靠静态字符串切 chunk） */
const loaders: Record<string, Record<string, () => Promise<{ default: object }>>> = {
  'zh-CN': {
    common: () => import('./locales/zh-CN/common.json'),
    dashboard: () => import('./locales/zh-CN/dashboard.json'),
    alertRule: () => import('./locales/zh-CN/alertRule.json'),
  },
  'en-US': {
    common: () => import('./locales/en-US/common.json'),
    dashboard: () => import('./locales/en-US/dashboard.json'),
    alertRule: () => import('./locales/en-US/alertRule.json'),
  },
};

export function lazyLoadNamespace(lng: string, ns: string): Promise<void> {
  touchedNamespaces.add(ns);
  if (i18n.hasResourceBundle(lng, ns)) return Promise.resolve(); // 已在内存（含远端合并包）
  const key = `${lng}:${ns}`;
  const pending = inflight.get(key);
  if (pending) return pending; // ★ 幂等：并发只发一次

  const task = (async () => {
    const loader = loaders[lng]?.[ns];
    if (!loader) throw new Error(`未注册的命名空间: ${lng}/${ns}`);
    const mod = await loader();
    // deep=true, overwrite=true：远端合并包若已先到（ns 首次注入就是远端内容），基线只补缺不覆盖远端
    i18n.addResourceBundle(lng, ns, mod.default, true, true);
  })().finally(() => inflight.delete(key));
  inflight.set(key, task);
  return task;
}

/** 路由进入前：一组 ns 就绪 */
export function ensureNamespaces(lng: string, nss: readonly string[]): Promise<void> {
  return Promise.all(nss.map((ns) => lazyLoadNamespace(lng, ns))).then(() => undefined);
}

/** 语言切换前：为新语言补齐本会话用过的全部 ns（先补齐再 changeLanguage = 原子切换） */
export function ensureLanguageLoaded(lng: AppLanguage): Promise<void> {
  return ensureNamespaces(lng, [...touchedNamespaces]);
}

/** 供路由懒加载合并（模式 A）：先 ns 后组件，组件首帧就有文案 */
```

### 4.2 RTL 镜像方案（M5）

```ts
// src/i18n/rtl.ts —— 方向判定 + <html> 同步 + JS 侧方向上下文
import { useEffect } from 'react';
import i18n from './index';
import type { Direction } from './types';

const RTL_LANGS = new Set(['ar', 'ar-SA', 'he', 'he-IL', 'fa', 'fa-IR', 'ur', 'ur-PK']);

/** 语言 → 排版方向。判定基于主语言标签（ar-EG 也是 rtl），不是整串匹配 */
export function dirFor(lng: string): Direction {
  return RTL_LANGS.has(lng.split('-')[0] ?? '') ? 'rtl' : 'ltr';
}

/** 挂在应用入口：语言变化即同步 <html lang/dir>（读屏语音、字体选择、CSS :lang 都依赖） */
export function syncDocumentDir(): void {
  document.documentElement.lang = i18n.language;
  document.documentElement.dir = dirFor(i18n.language); // RTL 总开关：一个属性驱动全局镜像
}

/** JS 侧方向上下文：一切"方向感知"的位移/动画代码的唯一入口。
 *  例：抽屉滑入动画 translateX(dirSign * 100%)、图表 y 轴位置、滑块方向 */
export function useDirection(): Direction {
  const lng = i18n.language;
  useEffect(() => syncDocumentDir(), [lng]);
  return dirFor(lng);
}

/** 方向感知位移符号：ltr=+1，rtl=-1。translateX 写死正负号的代码在 RTL 下必然反向 */
export function dirSign(dir: Direction): number {
  return dir === 'rtl' ? -1 : 1;
}
```

```css
/* 逻辑属性迁移——物理属性 → 逻辑属性对照（新代码禁物理方向属性）：
   margin-left        → margin-inline-start          行首外边距
   padding-right      → padding-inline-end           行尾内边距
   border-left        → border-inline-start          行首边框
   left/right（定位）  → inset-inline-start/end       行首/行尾偏移
```

### 4.3 双包合并的三道闸（M3，摘自图纸 10.4 的骨架）

```ts
// src/i18n/applyRemote.ts（骨架）—— 时序不可颠倒：先校验后注入，失败分级
export async function applyRemoteLocales(
  url: string, supported: readonly string[], timeoutMs = 5000,
): Promise<RemoteResult> {
  // 第 1 道：拉取（带超时）。失败 → warn + 基线（预期内降级，不告警）
  let payload: unknown;
  try {
    const res = await fetchWithTimeout(url, timeoutMs);
    if (!res.ok) throw new Error(`HTTP ${res.status}`);
    payload = await res.json();
  } catch (err) {
    console.warn('[i18n] 远端包拉取失败，使用基线包', err);
    return { status: 'fetch-failed', appliedLngs: [], reason: String(err) };
  }
  // 第 2 道：顶层结构校验。失败 → error + 整包丢弃（下发链路坏了，要人介入）
  const top = validateRemotePayload(payload);
  if (!top.ok) return { status: 'skipped', appliedLngs: [], reason: top.errors[0] };
  // 第 3 道：逐语言校验 + 深合并 + 注入（一个语言坏不影响其他语言）
  const appliedLngs: string[] = [];
  for (const lng of supported) {
    const nsMap = (payload as RemoteLocalePayload).packages[lng];
    if (!nsMap) continue;
    if (!validateNamespacePack(nsMap).ok) continue; // 该语言回退基线
    for (const [ns, remotePack] of Object.entries(nsMap)) {
      const baseline = i18n.getResourceBundle(lng, ns) ?? {};
      i18n.addResourceBundle(lng, ns, deepMerge(baseline, remotePack), true, true);
    }
    appliedLngs.push(lng);
  }
  if (appliedLngs.includes(i18n.language)) {
    i18n.emit('languageChanged', i18n.language); // 新增资源不自动通知，手动刷新订阅组件
  }
  return {
    status: appliedLngs.length === 0 ? 'skipped'
      : appliedLngs.length === supported.length ? 'applied' : 'partially-applied',
    version: (payload as RemoteLocalePayload).version,
    appliedLngs,
  };
}
// fetchWithTimeout / deepMerge / validateRemotePayload / validateNamespacePack：图纸 10.4（二）（三）原样搬
```

## 5. 坑与调试

1. **中文拼接无法翻译**（症状：上英文后 "Total 1 items" 单复数错，上俄语数量词全错）。根因：语序假设 + 复数类别（俄语 4 类、阿拉伯语 6 类）在拼接模型里没有表达位置——翻译单位是整句不是碎片。修法：一律整句 key + ICU；review 见 `+ n +` 拼接直接打回。
2. **ns 与组件 chunk 竞速闪裸 key**（症状：进页面一帧 key 再变文案）。根因：两个 chunk 并行加载，组件先渲染。修法：模式 A 串行（先 ns 后组件）或 `useSuspense: true` 挂到 Suspense 边界。
3. **注入后组件不刷新**（症状：远端包生效了，部分页面要刷新一次）。根因：`addResourceBundle` 不触发订阅。修法：注入后手动 `emit('languageChanged')`；懒加载基线只写内存缺失的 ns（`overwrite` 语义别把远端盖回去）。
4. **`useMemo([], ...)` 冻结旧文案**（症状：切语言后表格列头还是旧语言）。根因：`t` 的结果被空依赖 memo 冻结进闭包。修法：依赖加 `i18n.language`；或列定义只存 key 渲染期翻译（schema 联动的正统姿势——key 是数据，文案是视图）。
5. **`toLocaleDateString()` 输出随用户机器漂移**（症状：快照测试时好时坏）。根因：无参调用走机器 locale + 机器时区。修法：全站禁用，统一 `useFormatters`（locale/timeZone 永远显式）。
6. **服务器返回不带 Z 的时间串**（症状：北京用户 20:00、纽约用户 07:00、后端日志 12:00 三个"真相"）。根因：`new Date("2026-11-05 12:00:00")` 按浏览器本地时区解释裸串。修法：契约层写死 ISO 8601 带 Z；历史接口显式补 `Z` 再解析（`parseLegacyUtc`）。
7. **RTL 弹层定位飘**（症状：切 ar 后抽屉和遮罩一边一边）。根因：`left: 0` 物理属性不随 dir 反转，与逻辑属性混用后半镜像。修法：定位统一 `inset-inline-start`；全仓 grep `\b(left|right)\s*:` 逐个分诊。
8. **伪语言忘了做**（症状：德语翻译回来第一周按钮全爆）。根因：布局按中文两三个字定宽。修法：zz-PSEUDO 进日常开发（M6），按钮禁定宽改 `min-width`；字符预算和译者约定成文。
