# React 实战编码学习大纲（场景驱动版）

> 使用方式：每个场景 = 一个可运行的小 demo。先自己写，再对照官方文档修正。
> 预计周期：12–14 周（每天 1–2 小时），可按阶段跳过已掌握内容。
> 核心原则：**所有知识都落在"编码场景"上，不为学 API 而学 API。**
