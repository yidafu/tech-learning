## 复刻路线

1. **先复刻项目 0（公共底座）**——五个场景全部长在同一套内核上：组件注册表 + 递归渲染器 + 表达式引擎。底座不牢，后面每个项目都会卡在同样的问题上。
2. **项目 1（动态表单）是第一个完整落地**：用底座渲染真实 schema，接通受控数据流与校验。
3. **项目 2/3 二选一先做**：Form Builder 考"编辑态"（拖拽 + 画布 + 属性面板），仪表盘考"布局系统 + 第三方图表集成"，两者共用底座的拖拽与 undo 体系。
4. **项目 4（JSON 编辑器）最轻**，是 schema 树编辑的另一面，可与项目 2 并行。
5. **项目 5（低代码整合）是毕业项目**：把 1–4 的产物按平台架构拼装，加上页面协议、发布流程与权限位。

每本手册开头 §0 附"验收清单"，逐条打勾即复刻完成。
