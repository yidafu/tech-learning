# 浏览器与网络原理学习大纲

> 目标：从敲下 URL 到像素上屏，把「发起请求 → 收到 HTML → 渲染成用户看到的页面」整条链路的每一层吃透——导航决策、DNS、TCP/TLS、HTTP 协议、CDN 与服务端、浏览器缓存与调度、HTML/CSS/JS 解析、渲染管线、性能度量与优化。
> 用法：按阶段推进，学到哪一册就勾选对应条目；`[ ]` 未学，`[x]` 已完成。每册末尾有自测题，每阶段有实践任务——「看懂」不算数，在 DevTools 里量出来、在抓包里看到才算。

## 主时间线：全课程挂在一条 17 步主线上

本站所有内容都挂在下面这条主线上。每一册都能回答「它在时间线的哪一段」。第一阶段先建这本「总账本」（各段真实耗时量级），之后每个阶段回来核账一次。

```mermaid
flowchart LR
  A[① 输入 URL] --> B[② 导航决策<br>HSTS/SW/缓存/BFCache]
  B --> C[③ DNS 解析]
  C --> D[④ TCP 握手]
  D --> E[⑤ TLS 握手]
  E --> F[⑥ 发送 HTTP 请求]
  F --> G[⑦ 服务端处理<br>CDN/网关/SSR]
  G --> H[⑧ 响应回程<br>压缩/分块]
  H --> I[⑨ 网络进程接收<br>MIME/缓存]
  I --> J[⑩ commit +<br>渲染进程就位]
  J --> K[⑪ HTML→DOM<br>preload scanner]
  K --> L[⑫ CSS→CSSOM]
  L --> M[⑬ JS 编译执行]
  M --> N[⑭ Style 计算]
  N --> O[⑮ 布局→分层→绘制<br>→栅格化→合成]
  O --> P[⑯ 首帧上屏<br>FCP/LCP]
  P --> Q[⑰ 持续交互<br>输入→重渲染]
```

| 步骤 | 发生在哪 | 本站哪个阶段讲 |
|---|---|---|
| ①② | 浏览器 UI 进程 | 第一、二阶段 |
| ③④⑤ | 操作系统网络栈 | 第三阶段 |
| ⑥ | 网络进程 | 第四阶段 |
| ⑦⑧ | 服务端与网络 | 第五阶段 |
| ⑨⑩ | 网络进程 / Browser 进程 | 第二、六阶段 |
| ⑪⑫⑬⑭ | 渲染进程主线程 | 第七阶段 |
| ⑮ | 渲染进程主线程 + 合成线程 + GPU | 第八阶段 |
| ⑯⑰ | 全链路 | 第九阶段 |

**学完本站的验收标准**：拿任意一个真实站点，从地址栏敲下 URL 开始，把 17 步逐段在 DevTools / 抓包工具里指认出来，说出每一段花了多少毫秒、为什么、能怎么优化——这就是第十阶段的毕业项目。

## 第一阶段：全链路鸟瞰与度量基础

先看全景再钻细节。建立主时间线账本；认清浏览器由哪些进程线程组成；学会用 DevTools 的 Network 与 Performance 面板「量」而不是「猜」。

- [ ] 01-导览 · 阶段入口：主线总账本怎么记、度量环境怎么搭
- [ ] 02-从URL到首屏全景时间线与耗时账本 · 17 步逐段展开，本地/4G 弱网两套耗时量级表
- [ ] 03-浏览器组成-进程线程与站点隔离 · Chrome 多进程架构、Mojo IPC、渲染进程沙箱、Safari/Firefox 对比
- [ ] 04-度量基础-Network与Performance面板入门 · waterfall 逐列解读、请求生命周期四段、指标全景

**阶段实践**：录一次目标站点（毕业项目对象）的完整加载，把 17 步对号入座，产出第一版时间线账本。

## 第二阶段：发起请求之前——导航与浏览器决策

URL 敲下回车之后、第一个网络包飞出去之前，浏览器做了一串决策。这段常被忽略，却决定了「这次请求到底发不发、发给谁、要不要重用进程」。

- [ ] 01-导览 · 阶段入口
- [ ] 02-URL语法解析与地址栏决策 · RFC 3986 结构、百分号编码、IDN/Punycode、搜索词判定
- [ ] 03-导航决策链-HSTS-ServiceWorker-缓存与BFCache · 命中即不发请求的各条捷径、BFCache 拦路虎全表
- [ ] 04-导航执行-跨进程流转与commit · UI 进程→网络进程→渲染进程、为什么响应头到达才 commit
- [ ] 05-站点隔离深潜-frame tree与OOPIF · 跨站 iframe 为何独立进程、对事件与渲染的影响

**阶段实践**：构造一个命中 BFCache 与一个被 no-store 挡掉的往返导航，分别观察 Network 面板差异。

## 第三阶段：建立连接——DNS、TCP/UDP、ICMP 与 TLS

三个网络包出去之前的地基：域名变成 IP（DNS）、建立管道——可靠的 TCP 与轻量的 UDP、网络层的报信协议 ICMP、把管道升级成加密信道（TLS）。

- [ ] 01-导览 · 阶段入口
- [ ] 02-DNS解析全链路 · 逐级缓存与递归/迭代、TTL 与负缓存、报文格式与 EDNS0、SVCB/HTTPS 记录、DNSSEC、DoH/DoT、CDN 智能调度
- [ ] 03-TCP-三次握手与传输控制 · 状态机逐跳、SYN cookie、首部逐字段、可靠传输与重传/SACK、拥塞控制详解、TFO
- [ ] 04-UDP与ICMP-无连接传输与网络层信令 · UDP 头逐字段、无连接语义与报文边界、IP 分片的代价、ICMP 类型表、ping/traceroute 原理、PMTUD 与黑洞
- [ ] 05-TLS-从明文到加密信道 · HTTPS 概念厘清、密码学五件套、TLS 1.2 vs 1.3 逐消息、密钥推导链、证书链验证、SNI/ECH、ALPN、0-RTT 重放风险
- [ ] 06-实践-用抓包工具拆一次真实握手 · Wireshark + DevTools Security 面板逐包对照（含 ICMP 实验）

**阶段实践**：对自己部署的页面抓一次完整握手，逐包标注 SYN/ACK、ClientHello/ServerHello，对照 06 册。

## 第四阶段：HTTP 协议与请求语义

请求真正上路：报文怎么写、连接怎么复用、三代协议各自解决了什么又留下什么。

- [ ] 01-导览 · 阶段入口
- [ ] 02-HTTP1.1-报文语义与连接管理 · 报文结构、幂等性、keep-alive、队头阻塞、6 连接限制、0.9→1.0→1.1 版本演进史
- [ ] 03-HTTP2-分帧多路复用与优先级 · 二进制分帧、流状态机与依赖树、HPACK、SPDY→h2 演进史、TCP 层队头阻塞为何没解决
- [ ] 04-HTTP3与QUIC · gQUIC→IETF QUIC 演进史、握手与传输合并、连接迁移、流级流控、0-RTT 风险、部署现状
- [ ] 05-请求语义-协商-Cookie-条件请求与Range · 内容协商、Set-Cookie 属性全解、ETag/Last-Modified、断点续传

**阶段实践**：同一站点分别在 HTTP/1.1、h2、h3 下加载，对比 Network 面板的请求并行度与总耗时。

## 第五阶段：服务端与响应回程

视角切到对端：请求穿过 CDN 与网关，服务端把 HTML 生成出来，响应沿原路压缩、分块、流回浏览器。

- [ ] 01-导览 · 阶段入口
- [ ] 02-CDN-边缘-回源与调度 · 缓存键、命中/回源、stale-while-revalidate、103 Early Hints
- [ ] 03-负载均衡-网关与反向代理 · L4/L7、Nginx 事件驱动模型、限流熔断在浏览器侧的表现
- [ ] 04-服务端如何生成HTML-模板-SSR与流式 · 模板渲染、流式 SSR、状态注入、TTFB 构成逐项拆解
- [ ] 05-响应回程-压缩-分块与连接复用 · gzip/brotli/zstd 权衡、chunked、连接池复用时序
- [ ] 06-错误-重定向与失败模式 · 3xx 全家族、缓存下的重定向、网络栈自动重试、超时定位

**阶段实践**：用 curl -v 拆解目标站点响应头全家族，找出压缩方式、缓存指令与重定向链。

## 第六阶段：资源到达——接收、缓存与子资源调度

HTML 字节进入浏览器：接收流水线如何分流、HTTP 缓存如何判定、Service Worker 如何拦截、子资源如何排队上路。

- [ ] 01-导览 · 阶段入口
- [ ] 02-网络进程接收流水线 · MIME sniffing 与 nosniff、CORB/ORB、首字节到达即开始的乐观准备
- [ ] 03-HTTP缓存体系全解 · Cache-Control 指令全表、启发式缓存、强缓存/协商缓存判定流程
- [ ] 04-ServiceWorker-生命周期与拦截时序 · install/activate/waiting、respondWith 时序、与 HTTP 缓存叠加
- [ ] 05-子资源调度-预解析扫描器-优先级与资源hint · 预解析扫描器（preload scanner）、优先级表、preload/prefetch/fetchpriority、Speculation Rules
- [ ] 06-脚本加载模型-阻塞-defer-async与module · 双重阻塞、三张时序图、DOMContentLoaded 被谁推迟

**阶段实践**：给页面分别加 `Cache-Control` 各指令组合，用 Network 面板「Size 列（disk cache/memory cache）」验证判定路径。

## 第七阶段：解析与构建——HTML、CSS、JS 变成可计算的数据

渲染进程主线程把字节流变成三棵树（DOM/CSSOM）+ 一套可执行代码。词法语法理论不重复造轮子，详读指向 compiler 站。

- [ ] 01-导览 · 阶段入口
- [ ] 02-从字节到字符-编码判定与解码 · BOM→HTTP 头→meta 前 1024 字节→默认，乱码成因分类
- [ ] 03-HTML解析器-状态机-容错与DOM构建 · 规范分词状态机、树构建、著名容错规则、meta charset 位置之谜
- [ ] 04-CSS解析与CSSOM · 语法分析、@import 串行灾难、媒体查询与阻塞规则、@layer/@scope
- [ ] 05-样式计算-级联-匹配与ComputedStyle · 右到左匹配、级联算法、规则分桶与祖先过滤器、强制同步布局第一现场
- [ ] 06-V8执行模型-从源码到优化机器码 · Ignition/Sparkplug/Maglev/Turbofan、内联缓存、隐藏类、去优化（词法语法理论详见 compiler 站）
- [ ] 07-事件循环与任务调度-渲染在哪里发生 · 一次循环完整步骤、宏/微任务、rAF 的确切位置、长任务与 yield 模式

**阶段实践**：用 Performance 面板抓一次 Parse HTML → Recalculate Style → 主线程脚本执行的完整 trace，对照各册。

## 第八阶段：渲染管线——从树到像素

DOM + CSSOM 之后，像素是怎么一步步画出来、贴到屏幕上的。这一阶段同时是 `gui/` 站（自绘框架渲染调度）的平台对照面。

- [ ] 01-导览 · 阶段入口
- [ ] 02-渲染树与LayoutNG-fragment树 · RenderObject、display:none vs visibility、伪元素与匿名盒、现代 Blink 架构
- [ ] 03-布局-盒模型-格式化上下文与布局抖动 · BFC 规则全表、margin 合并、IFC、Flex/Grid 算法概览、layout thrashing 治理
- [ ] 04-分层-PaintLayer-合成层与层爆炸 · 提升合成层条件全表、will-change 的代价、DevTools Layers 实测
- [ ] 05-绘制与栅格化-display list-瓦片与Skia · 绘制指令记录、瓦片、软件 vs GPU 光栅（GPU 侧详见 webgl 站）
- [ ] 06-合成-合成线程-GPU与vsync · 合成器架构、合成帧提交、vsync 节拍、滚动为何不经主线程
- [ ] 07-一帧的完整生命周期-失效传播与帧预算 · 一次 JS 修改到像素的传播路径、16.6ms 帧预算、trace 逐段对照

**阶段实践**：故意制造层爆炸与布局抖动各一次，用 Performance + Layers 面板定位并修复。

## 第九阶段：首屏、交互与持续渲染

从「能渲染」到「渲染得好」：首屏怎么被拖慢、指标怎么算出来、交互之后的重渲染链路、SSR 之后的水合时代。

- [ ] 01-导览 · 阶段入口
- [ ] 02-关键渲染路径与首屏呈现 · CRP 精确定义、白屏/FOUC 案例、关键 CSS 内联、字体 FOIT/FOT
- [ ] 03-性能指标深潜-FCP-LCP-CLS-INP测量原理 · 候选元素判定与剔除规则、CLS session window、INP 三段构成
- [ ] 04-加载优化手法手册 · 资源 hint 全用法、图片优化、代码分割与预取、每手法附收益与陷阱
- [ ] 05-输入事件链路与交互渲染 · 合成器直接处理的输入、hit test、passive listener、交互后重渲染全链路
- [ ] 06-水合与下一代渲染架构 · hydration 谱系、islands、RSC 与流式（框架层详见 react 站）、View Transitions、content-visibility

**阶段实践**：把目标站点的 LCP/CLS/INP 量出来并归因到具体资源/元素，列出优化清单。
