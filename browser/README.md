# 浏览器与网络原理学习站（文档站）

从敲下 URL 到像素上屏，沿一次真实请求走完全链路：导航决策 → DNS / TCP / TLS 建连 → HTTP 协议 → CDN 与服务端响应 → 浏览器接收与缓存 → HTML/CSS/JS 解析构建 → 渲染管线（布局 → 分层 → 绘制 → 栅格化 → 合成）→ 首屏指标与交互渲染。十个阶段，约 46 册，终点是「对任意真实站点做出全链路测量与优化报告」的毕业项目。使用 **Docusaurus 3** 构建。

## 本地运行

```bash
npm install    # 首次安装依赖
npm run dev    # 开发模式，http://localhost:3009
npm run build  # 构建静态站点到 build/
npm run serve  # 本地预览构建产物
```

> 本站讲的不是某个框架的渲染（React 归 `react/` 站、RN 归 `react-native/` 站、自绘框架归 `gui/` 站），而是浏览器与网络这个平台本身：框架站讲「在上层怎么用」，本站讲「底下发生了什么」。

## 目录结构

| 路径 | 说明 |
|------|------|
| `docusaurus.config.js` | 站点配置（标题 / 十阶段导航 / 站群互链） |
| `sidebars.js` | 侧边栏顶层显式声明（大纲 → 十阶段），阶段内部按目录自动生成 |
| `docs/` | 学习大纲 + 十个阶段（每阶段 `01-导览.md` 为入口，笔记保持无 frontmatter） |
| `src/pages/index.js` | 站群统一模板首页（阅读顺序 + 阶段卡片） |
| `src/css/custom.css`、`src/components/site/`、`static/img/` | 站群统一主题（由 `shared/sync-theme.mjs` 同步，勿手改） |
| `patches/docusaurus-graph+2.0.0.patch` | 子路径部署补丁（fetch 路径 + 节点 id 修复，见仓库根 README） |
| `labs/` | 动手实验材料（抓包记录、trace 文件、复现页面），随分册逐步补充 |

## 十个阶段

| # | 阶段 | 定位 | 站内路径 |
|---|------|------|----------|
| 1 | 全链路鸟瞰与度量基础 | 17 步主时间线、进程架构、度量工具 | `/docs/第一阶段/导览` |
| 2 | 发起请求之前 | URL 解析、导航决策链、BFCache、站点隔离 | `/docs/第二阶段/导览` |
| 3 | 建立连接 | DNS、TCP、TLS 与抓包实验 | `/docs/第三阶段/导览` |
| 4 | HTTP 协议与请求语义 | HTTP/1.1 → 2 → 3、协商与条件请求 | `/docs/第四阶段/导览` |
| 5 | 服务端与响应回程 | CDN、网关、SSR、压缩与流式 | `/docs/第五阶段/导览` |
| 6 | 接收、缓存与调度 | HTTP 缓存、Service Worker、preload scanner | `/docs/第六阶段/导览` |
| 7 | 解析与构建 | HTML/CSS 解析、样式计算、V8、事件循环 | `/docs/第七阶段/导览` |
| 8 | 渲染管线 | 布局、分层、绘制、栅格化、合成、一帧生命周期 | `/docs/第八阶段/导览` |
| 9 | 首屏与交互 | 关键渲染路径、指标体系、输入链路、水合 | `/docs/第九阶段/导览` |
| 10 | 实战与毕业 | DevTools 深潜、案例复盘、全链路优化报告 | `/docs/第十阶段/导览` |

学习方式：每一册都挂在「17 步主时间线」的一段上，第一册先建总账本（各段耗时量级），之后每个阶段回来核账；每阶段末尾有自测题，第十阶段以毕业项目收束。
