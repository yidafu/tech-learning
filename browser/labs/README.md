# labs/ —— 动手实验材料

本目录存放各分册实验的原始凭证与复现材料（不入站内文档路由，仅随仓库走）：

- `trace-*.json`：Performance 面板导出的加载 trace（按 `日期-环境-场景` 命名）
- `har-*.har`：Network 面板导出的请求归档
- `repro/`：复现问题的最小 HTML/JS 页面（白屏、布局抖动、层爆炸等）

约定（见第一阶段 04 册「度量纪律」）：

1. 每份账本数字必须能回溯到这里的原始凭证；
2. 文件名带日期与环境（节流参数），冷/热缓存分开命名；
3. 毕业项目（第十阶段 05 册）的基线与三轮复测凭证全部归档在本目录。
