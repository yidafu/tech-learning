## 二、交互式学习平台（重点推荐）

### PortSwigger Web Security Academy（Web 安全首选）

- 网址：<https://portswigger.net/web-security> ｜ 语言：英语（部分有社区中译）｜ 免费 ｜ 适合阶段：3、7（Web）
- 由 Burp Suite 开发商 PortSwigger（Dafydd Stuttard，即《Web Application Hacker's Handbook》作者）运营：**完全免费**、按漏洞模块组织、每个主题附带可在线访问的实验环境（Labs）、有官方学习路径与进度追踪，完成后可考 Burp 认证。
- 学习路径建议：
  1. 先修：Burp Suite 基础模块（拦截、重放、站地图）；
  2. 入门模块顺序：SQL injection → XSS → CSRF → Authentication（认证）→ Access control（访问控制）；
  3. 进阶：File upload → Command injection → SSRF → Business logic（业务逻辑）→ 反序列化；
  4. 全部走 Apprentice（学徒级）实验，再按需刷 Practitioner 级。

### OverTheWire（Wargame 关卡制）

- 网址：<https://overthewire.org/wargames/> ｜ 英语 ｜ 免费 ｜ 适合阶段：1、3、4
- SSH 关卡式闯关，推荐路线：**Bandit**（0→34 关，练 Linux 命令行、文件权限、文本处理，对应阶段 1）→ **Natas**（Web 安全，对应阶段 3）→ **Narnia / Behemoth**（简单二进制利用，对应阶段 4 入门）→ Maze / Vortex 等更硬核关卡。
- 每关只需 SSH 和终端，是"零成本开局"的最佳选择。

### pwnable.kr（Pwn 入门）

- 网址：<https://pwnable.kr> ｜ 英语 ｜ 免费 ｜ 适合阶段：4、7
- 经典韩国 Pwn 闯关站，"Toddler's Bottle" 区的 **fd / collision / bof** 三题是全球公认的二进制入门第一课：分别对应文件描述符、整数碰撞、栈溢出。之后按 Rookiss 等区逐级深入。

### pwnable.tw（Pwn 进阶）

- 网址：<https://pwnable.tw> ｜ 英语 ｜ 免费 ｜ 适合阶段：4、7
- 同团队风格的进阶版，从 start、orw 等题开始，题量少而精，保护机制齐全，适合在 pwnable.kr 毕业后进阶。

### CryptoHack（模块化密码学挑战）

- 网址：<https://cryptohack.org> ｜ 英语 ｜ 免费 ｜ 适合阶段：2、7（Crypto）
- 密码学方向的"闯关版教材"：按数学基础、对称、公钥（RSA/ECC）、哈希等模块组织，每关自带简短讲义，做题即学习；与《图解密码技术》互补。

### picoGym（picoCTF 练习场）

- 网址：<https://picoctf.org>（Practice 页面）｜ 英语 ｜ 免费 ｜ 适合阶段：7
- picoCTF 历年真题的永久免费练习场，题目按难度与方向分类，难度曲线平缓，是 CTF 入门（配合笔记 35 篇）最合适的起步题库。

### HackTheBox（Academy vs Machines）

- 网址：<https://www.hackthebox.com> / <https://academy.hackthebox.com> ｜ 英语 ｜ 免费层 + 订阅 ｜ 适合阶段：5、7
- 两者区别：**Academy** 是结构化课程平台（模块化教材 + 专属实验靶机，部分模块免费、完整路径订阅制），适合"学"；**Machines** 是接近真实场景的靶机（活跃机免费开放有限，退役机多需 VIP），适合"练"。建议先 Academy 补模块，再打 Machines 检验。

### TryHackMe（路径制学习）

- 网址：<https://tryhackme.com> ｜ 英语 ｜ 免费房间 + 订阅 ｜ 适合阶段：1—7 皆有条线路径
- "房间（Room）"任务制 + 引导式问答，新手友好。推荐路径：**Pre Security**（阶段 1）→ **Cyber Security 101**（阶段 2）→ **Jr Penetration Tester**（阶段 3/5，攻防向）或 **SOC Level 1**（阶段 5/6，防御向）。

**CTF Wiki（重点详细介绍）**

- 网址：<https://ctf-wiki.org>（开源仓库 [github.com/ctf-wiki/ctf-wiki](https://github.com/ctf-wiki/ctf-wiki)）｜ 中文 ｜ 免费 ｜ 适合阶段：7（辐射 3、4）
- 国内最有影响力的 CTF 中文百科：按 MISC / Crypto / Web / Reverse / Pwn（含 Windows、IoT 等扩展方向）组织知识体系，每个方向从环境搭建、基础概念讲到经典题型，附大量例题与 writeup 引用。它是阶段 7 各方向笔记（36—40 篇）的天然配套教材，也是查"这个方向都有什么考点"的第一索引。

**博客与公众号**

- 个人博客：P 牛（phithon，长亭科技联合创始人）的博客 [离别歌](https://www.leavesongs.com)，Web 安全（PHP/Java 反序列化、代码审计）深度长文的标杆。
- 阮一峰《[科技爱好者周刊](https://www.ruanyifeng.com/blog/)》：每周更新的科技周刊，常含安全话题与工具推荐，适合保持视野。
- 公众号：各安全厂商实验室公众号（如腾讯玄武实验室等）会发布高质量技术分析与年度盘点，按兴趣关注即可，不必贪多。
