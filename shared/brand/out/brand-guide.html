站群 Logo 与视觉规范

11 个技术学习站点的标记系统：一个底板语言、11 个等距色相、4 种必备变体。 全部为可编辑 SVG 几何路径，不含位图、渐变与文字。

方向：A 模块方块 + 每站一色（OKLCH 同亮度同彩度，色相 32.7° 等距）
锚点色：#2e7cf6（architecture 的 Logo 底板）· 文档主色由各自 Logo 色派生，见「文档主题色」
唯一源头：shared/brand/build.py · 手册由 guide.py 生成

为什么是这个方向

11 个标记会大量并排出现（落地页网格、各站「站群导航」下拉、浏览器书签栏），因此家族一致性 优先于单体表现力。蓝底圆角方块提供统一底板，形状承担识别，颜色只做辅助——这也是在 16px 下仍能区分的前提。

方向16px 可读家族感结论
A 模块方块（采用）好最强自带色块，网格排布整齐，深浅底边界清楚
B 字母笔画最好中视觉重量偏轻，卡片里显弱
C 分层剖面差强斜层在 16px 糊成一团
统一亮度是硬约束。11 个底板在 OKLCH 下取同一 L、同一 C，只换色相， 因此白色图案对每一块底板的对比度都落在 3.93–3.96，视觉重量完全一致。代价是黄绿色相在这 个亮度下必然偏暗（js-ts #967f05、compiler #618d04）， 这是为了让白图在全部 11 站都站得住，不是选色失误。

色相按 32.7° 等距排布，红与粉相邻，暖色区必然拥挤。因此形状必须能独立完成识别： 把任一标记转成灰度，仍应能说出是哪一站。

四个必备变体

9 个自研站：同一份几何，四种用途——深色版只把底板提亮一档（亮度 0.255），图案仍是纯白； 单色版去掉底板、改用 currentColor，用于单色印刷与任意底色嵌入。

react / react-native：只有官方定版的两档（浅底 logo.svg、 深底 logo-dark.svg）。小尺寸版是同一几何等比放大占位比， 不是重绘；不提供单色版，因为给他人商标做单色化属于改动。

文档主题色

Logo 的底板色是「白字压色块」的用法：白色图案对 11 块底板的对比度都在 3.93–3.96。 同一个颜色直接拿去当行内链接、正文强调色、按钮文字，就只有 3.9:1——低于 WCAG AA 要求的 4.5:1。要让「站点看起来确实是它的颜色」与「正文读得清」同时成立， 规则是保色相、降亮度：色相与彩度不动，只把亮度解到刚好过线。

派生规则：OKLCH 色相与彩度保持不变，亮度下移约 0.035 （各站 ΔL 记在 brand-spec.json 的 lumFromLogo），使白底对比度落到 4.54–4.57；深色模式另解一档， 使 #1b1b1d 上的对比度同样过 4.5。色相偏移全部 < 0.1°。

两个例外值得单独说明：

  • react：官方蓝 #087EA4 本身对白底 4.64:1，已经过线， 因此主色就是官方色，未做任何调整。
  • react-native：官方青 #61DAFB 对白底只有 1.9:1， 当正文色不可能成立。压到同色相的 #00819b 才能过 AA—— 这是 11 站里唯一与 Logo 观感差别较大的一站，属于官方定色带来的必然结果。

建议最小值（基于本次实测，不构成通用结论）： 小尺寸版与 favicon ≥ 16px；主标 ≥ 32px；单色版 ≥ 20px。 低于这些尺寸时，圆角底板的曲率与最细的 4 单位描边会开始丢失。

留白与最小间距

留白 = 底板宽度的 1/4（64 栅格即 16 单位），四周等量。任何相邻文字、 其它标记、容器边缘都不得侵入该区域。

落在深色底上时改用 logo-dark.svg，留白规则不变。

误用

禁止原因
非等比拉伸圆角与描边粗细失衡，16px 下会变形
换成未登记的底色或图案色破坏 11 站的等亮度关系，白图对比度失效
加描边、投影、外发光标记本身是平涂几何，加效果会在小尺寸变成脏边
旋转、倾斜、拆分母题元素母题的辨识依赖固定角度与相对位置
在杂乱照片上直接放单色版单色版靠形状识别，需要干净底或加实色底板
把底板裁成非圆角方块圆角 14/64 是家族的统一特征

两个标志形状相同，这是官方事实而非失误。React Native 没有独立的图形标志， reactnative.dev 的头部标志就是 React 原子（青色描边版）。因此这两站在 11 个标记的网格里 只能靠描边/填充与色相区分，不能像其它 9 站那样靠形状区分。若你更看重网格里的 辨识度，可把 react-native 退回站群自研的「Bridge」母题（双侧立柱 + 通道）， 执行时把该站从 build.py 的 OFFICIAL 里移除即可。
官方标志的既有弱点一并继承：React Native 的 #61DAFB 在白底上对比度约 1.9:1，16px 下两者都会糊成色块。这是官方定版的结果，不做「优化」。

权利与授权

  • 标志（9 站）：architecture / observability / compiler / js-ts / browser / security / backend / webgl / gui 的母题为本次原创几何，未复制、未参考任何现有商标的造型； 不构成商标可注册性判断，也未做冲突检索。
  • 标志（2 站）：react 与 react-native 按要求直接使用官方标志，权利人 Meta Platforms, Inc.，文件来自官方仓库（reactjs/react.dev 的 public/images/brand/、facebook/react-native-website 的 header_logo.svg）。几何、配色均未改动，不提供单色版 ——改色或重绘等于修改他人商标。用途仅限指代该技术本身的教学站点，不暗示官方背书。
  • 字体：系统内不含任何文字，因此不依赖字体授权，也不存在把字体转曲绕过许可的问题。 站名一律由站点的 HTML 文本承担。
  • 图像：无位图素材。所有 PNG 均由本仓 SVG 用 rsvg-convert 导出， 可随时重新生成。
  • 旧资源：shared/static/img/{logo,favicon}.svg（蓝底书本）已废弃并删除， 其图形不再出现在任何站点。
