## 知识点地图

### 1. 数据流分析（[正册 02](02-数据流分析.md)）

- **不动点框架**：每个程序点关联一个"事实集合"（如"哪些变量在此点活跃"），沿 CFG 边传播直到不再变化。收敛性来自"半格 + 单调函数"（Kleene 不动点定理）——理解直觉即可：事实只增不减，有限集合必然到头。
- **worklist 算法**：待处理节点队列，处理一个节点若其 out 变化则后继入队——比"反复全图扫描直到无变化"高效。
- **三大经典分析**：
  - 到达定值：哪些赋值能到达此点（用于公共子表达式）。
  - 活跃变量：此点之后还会被读的变量（用于死代码消除与寄存器分配）。
  - 可用表达式：哪些表达式已算过且操作数未变（用于 CSE）。

### 2. SSA 与经典优化（[正册 03 SSA 构建](03-SSA构建.md)、[正册 04 经典优化 pass](04-经典优化pass.md)）

- **SSA（静态单赋值）**：每个变量名只赋值一次；分支汇合处 `x3 = φ(x1, x2)` 表示"按来路取值"。`y = x*0; z = y + 1` 这类优化在 SSA 上变成局部的图模式匹配——这是 SSA 让优化变简单的本质。
- **构建入门**：支配树（谁必经谁）、支配边界（φ 必须插的位置）→ 插 φ → 重命名（DFS 沿支配树压栈）。完整实现较重，本阶段理解算法 + 用工具可视化即可。
- **经典 pass 清单**：
  - 常量折叠：编译期算出 `2 * 3` → `6`（注意浮点与溢出的边界，编译器不允许改变可观察行为）。
  - 常量传播：`x = 6; y = x + 1` → `y = 7`，配合折叠形成"传播-折叠"固定点循环。
  - 死代码消除：无副作用 + 结果不被读 → 删（活跃变量分析给答案）。
  - 公共子表达式消除（CSE）：同表达式同操作数 → 复用第一个结果。
  - 复制传播：`a = b; use(a)` → `use(b)`。
  - 窥孔优化：目标码层面的局部模式替换（`JMP next` 删除、`ADD 0` 删除）——最便宜也最实用。
- **循环优化**：不变量外提（LICM，把循环里不变的计算搬出去）、归纳变量简化（`for i: a[i]` 的地址递推）。

### 3. JIT 视角（概念，[正册 05](05-JIT视角.md)）

- **内联缓存（IC）**：同调用点的函数类型稳定时，把"查方法"固化为"直接调用 + 守卫"——V8 内联缓存也是"运行时的窥孔优化"。
- **隐藏类（hidden class）**：相同形状的对象共享布局描述，属性访问从哈希查找退化为偏移量访问。
- **方法内联 + 逃逸分析 + 去优化**：内联是"优化之母"（给了所有跨函数分析的可能）；逃逸分析判断对象是否逃出函数（不逃 → 栈分配/标量替换）；假设不成立时去优化（deopt）回解释器——JIT 的所有激进优化都建立在"错了能回退"之上。

### 4. 前端工程中的编译优化对照（[正册 06](06-前端工程优化对照.md)）

- **tree-shaking**：ESM 静态结构 → 模块图的可达性分析——本质是"以导出为根的标记-清除"（与 GC 同构！）。副作用标注（`sideEffects: false`）= 放宽"可达即活"的保守假设。
- **minify**：符号重命名（mangle）= 变量重命名（保持引用一致，作用域分析支撑）；语法级压缩 = 窥孔优化（`if(!0)` → 直接执行）；死代码消除同源。
- **scope hoisting**：把模块作用域拍平进单函数——一次"函数内联"式的提升，消灭模块包装函数的运行时开销。
- **sourcemap**：VLQ 变长编码的"生成位置 → 源位置"映射表——编译器位置追踪（第二、三阶段的 start/end）的最终变现。

## 与 mini 语言项目的关系

交付 `packages/optimizer`：字节码层面的常量折叠 + 常量传播 + 死代码消除三连 pass，`mini build --optimize` 开启。基准用第五阶段的 fib / 字符串拼接 / 高阶函数三组，跑 tinybench 前后对照并写收益分析（哪些负载收益大、哪些毫无变化、为什么）。
