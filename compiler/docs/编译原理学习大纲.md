# 编译原理学习大纲

> 目标：从零掌握编译器核心原理，用 TypeScript 实现一门完整 mini 语言（词法 → 语法 → 语义 → IR → 字节码 VM → GC → 优化），并读懂、扩展 Babel / TypeScript / esbuild 等前端工具链。
> 用法：按阶段推进，学到哪一节就勾选对应条目；`[ ]` 未学，`[x]` 已完成。每阶段末尾有实践任务，"看懂"不算数，跑起来才算。

**贯穿项目：mini 语言生长路线**

| 阶段完成后 | mini 语言获得的能力 | 产出物 |
|---|---|---|
| 二 | 变量、四则运算、比较 | token 流 + lexer 测试集 |
| 三 | if/else、while、fn、块作用域 | AST + 多错误报告 |
| 四 | 类型标注与推导 | 符号表 + 类型检查器 |
| 五 | 函数一等公民、闭包、数组、字符串 | 字节码 + VM + REPL |
| 六 | 动态内存 | 标记-清除 GC |
| 七 | — | 常量折叠、DCE 等 pass |
| 八 | — | WASM 后端（选做）/ Babel 插件 |

## 第一阶段：编译器全局观与语言基础（2 周）

> 本阶段导览（分册索引）：[01-第一阶段/01-导览.md](01-第一阶段/01-导览.md)

- [ ] 1. 编译器是什么
  - 编译器 vs 解释器 vs 转译器；AOT vs JIT
  - 经典流水线全景：词法 → 语法 → 语义 → IR → 优化 → 代码生成 → 链接/加载
  - 前端 / 中端 / 后端的划分；pass 的概念
  - 自举（bootstrapping）：编译器如何编译自己；交叉编译与增量编译
- [ ] 2. 前端工具链对照定位
  - Babel / TypeScript / esbuild / SWC / V8 各自负责哪一段
  - V8 分层编译：Ignition（字节码）→ Sparkplug → Maglev → TurboFan
  - 一行代码的旅程：从 `.ts` 源码到浏览器执行
- [ ] 3. 形式语言基础
  - 字母表、串、语言的形式化定义；文法四元组 G = (N, T, P, S)
  - BNF / EBNF 表示法与相互转换
  - 乔姆斯基谱系：0~3 型文法；正则语言与上下文无关语言的边界
  - 二义性文法：悬空 else（dangling else）、表达式文法的设计陷阱

  - monorepo 布局：packages/lexer、parser、checker、ir、vm、cli
  - 测试策略：黄金快照测试（源码 → AST/字节码）、错误用例集

## 第二阶段：词法分析（2 周）

> 本阶段导览（分册索引）：[02-第二阶段/01-导览.md](02-第二阶段/01-导览.md)

- [ ] 1. 理论：从正则到自动机
  - 正则表达式的形式化语义
  - Thompson 构造：正则 → NFA
  - 子集构造：NFA → DFA；DFA 最小化（Hopcroft 算法）一瞥
  - 为什么 lexer 用正则就够、parser 必须上下文无关
- [ ] 2. 手写 lexer 工程实现
  - token 定义：kind、lexeme、字面量解析（数值进制、转义字符串）、start/end 位置
  - 状态机写法：循环 + switch；最长匹配（maximal munch）原则
  - 关键字表 vs 标识符识别；保留字策略
  - 注释处理；换行敏感语言（Python 缩进）与分号自动插入（JS ASI）对照
  - Unicode：标识符分类、UTF-8/UTF-16 编码坑
- [ ] 3. 错误处理与生成器对照
  - 非法字符、未闭合字符串/模板：错误恢复后继续扫描
  - lex/flex、re2c 等生成器；为什么现代项目又回归手写
- [ ] 实践任务：实现 mini 语言 lexer（含多行字符串与多种数值字面量），位置精确到 行:列，快照测试覆盖正常与错误用例

## 第三阶段：语法分析与 AST（3~4 周）

> 本阶段导览（分册索引）：[03-第三阶段/01-导览.md](03-第三阶段/01-导览.md)

- [ ] 1. 自顶向下：LL 族
  - 推导与归约；最左/最右推导
  - 递归下降：函数即非终结符；文法到代码的机械翻译
  - FIRST / FOLLOW 集合与 LL(1) 判定
  - 左递归消除与提取公因子；packrat/PEG 一瞥
- [ ] 2. 运算符优先级：Pratt 解析（重点）
  - Pratt / 优先级爬升：绑定力（binding power）模型
  - 前缀/中缀/后缀统一处理；右结合如何表达
  - 为什么 acorn、swc、rustc 都用它
- [ ] 3. 自底向上：LR 族
  - 移进-归约模型、句柄与项目集
  - LR(0) → SLR → LR(1) → LALR 演进；状态机规模的权衡
  - 移进/归约冲突、归约/归约冲突；优先级与结合性如何消解
  - yacc/bison 与生成器的取舍
- [ ] 4. AST 设计与错误恢复
  - 节点类型：表达式/语句/声明；discriminated union + visitor（ADT 视角详见第四阶段补充分册）
  - 位置信息与 source span；AST 的可遍历/可变换性设计
  - 错误恢复：同步点（`;`、`}`）策略、panic mode；一次报多个错
  - 对照阅读：ESTree 规范；acorn 如何处理 ASI 与宽松模式
- [ ] 实践任务：Pratt + 递归下降混合 parser，产出 ESTree 风格 AST；准备 20+ 个语法错误用例，全部准确定位且不误报

## 第四阶段：语义分析与类型系统（3 周）

> 本阶段导览（分册索引）：[04-第四阶段/01-导览.md](04-第四阶段/01-导览.md)

- [ ] 1. 符号表与作用域
  - 词法 vs 动态作用域；静态语义 vs 动态语义
  - 作用域树与嵌套符号表；块作用域、函数作用域、模块作用域
  - 重定义、遮蔽（shadowing）、声明与使用顺序（TDZ 的语义）
  - 声明提升与自由/绑定变量判定
- [ ] 2. 类型系统

  - 结构化 vs 名义化类型；TypeScript = 结构化
  - 检查算法：自底向上综合（synthesis）与自顶向下检查

- [ ] 3. 类型推导（进阶）
  - Hindley-Milner 与合一（unification）算法入门
  - 泛型的两种实现：uniform representation（擦除）vs monomorphization

- [ ] 4. 检查器工程化
  - 双遍架构：resolve（建符号表）→ check（类型检查）
  - 诊断设计：错误码、hint、自动修复建议
