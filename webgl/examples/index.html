WebGL 示例工程

tech-learning / webgl 分册的递进式可运行示例：Vite + TypeScript，零运行时依赖。 运行方式见 README.md（npm install && npm run dev）。

  1. 01第一个三角形 VBO 上传、attribute 接线（stride/offset）、drawArrays 画一个渐变三角形
  2. 02自转 + 公转立方体 手写矩阵链 M = R(公转)·T(轨道)·R(倾斜)·R(自转)，perspective/lookAt 相机与深度测试
  3. 03纹理地球 canvas 程序化双纹理（零外部素材）+ Blinn-Phong 海洋高光 + 独立自转的透明云层
  4. 04数学库自检 minmath 最小集的运行时断言：黄金值 / 性质 / 往返三类用例在页面打印 PASS/FAIL
  5. 05轨道相机控制 球坐标参数化相机位置，拖拽旋转、滚轮指数缩放、帧率无关的阻尼收敛
  6. 06微型场景图 8 节点父子变换树：子节点只改局部自转角，公转由父"轨道节点"带动，双脏标记剪枝
  7. 07射线拾取 屏幕点逆投影成世界射线，Möller–Trumbore 逐三角形求交，悬停提亮 / 点击选中
  8. 08阴影与 PCF 软阴影 shadow map 两 pass（光源正交相机渲染深度），坡度感知 bias + 3x3 PCF，空格开关对比
  9. 09基于图像的光照 IBL 程序化 HDR 天空生成四份 IBL 资产（辐照度 / GGX 预滤波 / BRDF LUT），金属度-粗糙度球阵 PBR 合成
  10. 10屏幕空间环境光遮蔽 G-buffer(MRT) + 64 采样半球核 + 4x4 噪声旋转，盒滤波去噪后与光照合成，空格开关对比
  11. 11GPU 性能度量 EXT_disjoint_timer_query 分段计时（shadow/scene/post）与 CPU 帧统计并排，调片元负载观察 GPU 瓶颈形态
  12. 12级联阴影 CSM practical split 三级分割 + 深度纹理数组，纹素对齐消 shimmer，随级 bias 与级间 blend，按级染色 / 光锥线框调试
  13. 13视锥剔除与场景管理 视锥六平面提取 + 场景图层次 AABB 剔除（HUD 统计每帧测试 / 剪枝数），front-to-back 排序，被剔幽灵与视锥线框
各示例代码顶部注释标注了对应分册路径；公共层（gl / math / geometry / controls）提炼在 src/common/。
