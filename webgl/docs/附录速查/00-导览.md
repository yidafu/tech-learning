## 用法约定

- **入口**：主线或专题正文里遇到记不住的调用，直接跳对应小节；每张卡开头有小节导航表。
- **分工**：卡上只回答"是什么、怎么写"；"为什么、边界在哪"链回详解分册——例如 02 卡 2.2 限定符表与 [着色器语言专题/01-语言核心](../着色器语言专题/01-语言核心.md) 的关系就是"表 vs 规则课"。
- **版本口径**：与全站一致——WebGL2 上下文 + GLSL ES 1.00 主线，WebGL2 专有 API 单独标注（决策出处：[02-渲染管线全局观 1.3](../01-第一阶段/02-渲染管线全局观.md)，增量总表见 [07-WebGL2特性](../02-第二阶段/07-WebGL2特性.md)）。
- **打印**：每节按"一屏一主题"组织，可单节打印贴墙。
