## 3.1 初始化三件套

流程详解：[第一个 WebGL 程序 2.1](../01-第一阶段/03-第一个WebGL程序.md)；循环与 deltaTime：[引擎最小核心 2.1](../03-第三阶段/03-引擎最小核心.md)。

**上下文创建**：webgl2 优先、webgl 回退。

```typescript
export function createGLContext(canvas: HTMLCanvasElement): GL {
  const attrs: WebGLContextAttributes = { // 属性全表见 01 卡 1.1；不透明 3D 关 alpha 避免与页面背景错误合成
    alpha: false, antialias: true, depth: true, powerPreference: 'high-performance',
  };
  const gl = canvas.getContext('webgl2', attrs) ?? canvas.getContext('webgl', attrs);
  if (!gl) throw new Error('WebGL 不可用：被浏览器禁用或驱动不支持');
  return gl as GL; // 属性只在第一次 getContext 时生效，之前拿过 2d 上下文的 canvas 会返回 null
}
```

**resize 自适应**：CSS 尺寸 × DPR = 绘冲尺寸，变了才动手。

```typescript
export function resizeCanvas(canvas: HTMLCanvasElement, gl: GL, maxDPR = 2): boolean {
  const dpr = Math.min(window.devicePixelRatio || 1, maxDPR); // 夹上限：移动端省电省带宽
  const w = Math.round(canvas.clientWidth * dpr), h = Math.round(canvas.clientHeight * dpr);
  if (canvas.width !== w || canvas.height !== h) { // 没变就别碰：改 width 会清空绘冲
    canvas.width = w; canvas.height = h; gl.viewport(0, 0, w, h);
    return true; // true = 分辨率变了，FBO 该重建（3.5）
  }
  return false;
}
```

- 注意：每帧开头调用；DPR 策略详见 [移动端与兼容性 2.3](../工程专题/02-移动端与兼容性.md)。

**rAF 循环骨架**：deltaTime 版，切后台不爆炸。

```typescript
export function startRenderLoop(frame: (dt: number, elapsed: number) => void, maxDt = 0.1): (() => void) {
  let last = performance.now(), raf = 0;
  const tick = (now: number) => {
    const dt = Math.min((now - last) / 1000, maxDt); // 后台回来 dt 巨大，夹住
    last = now; frame(dt, now / 1000);
    raf = requestAnimationFrame(tick);
  };
  raf = requestAnimationFrame(tick);
  return () => cancelAnimationFrame(raf); // 返回停止函数
}
```

- 注意：动画一律吃 dt / elapsed，不依赖帧计数（与 [GLSL Cookbook](../技术专题/01-GLSL%20Cookbook.md) 全篇约定一致）。

## 3.2 着色器工具

流程详解：[第一个 WebGL 程序 2.3](../01-第一阶段/03-第一个WebGL程序.md)；错误清单：[ES3 特性 5.6](../着色器语言专题/05-ES3特性与调试规范.md)。

**编译 + 带行号报错**：日志行号直接对上源码。

```typescript
export function compileShader(gl: GL, type: number, source: string): WebGLShader {
  const shader = gl.createShader(type)!;
  gl.shaderSource(shader, source); gl.compileShader(shader);
  if (!gl.getShaderParameter(shader, gl.COMPILE_STATUS)) {
    const log = gl.getShaderInfoLog(shader) ?? '(无日志)';
    const numbered = source.split('\n')
      .map((line, i) => `${String(i + 1).padStart(4)} | ${line}`).join('\n'); // 对照 "ERROR: 0:行号"
    console.error(`着色器编译失败\n${log}\n---- 带行号源码 ----\n${numbered}`);
    gl.deleteShader(shader);
    throw new Error(`shader compile failed: ${log.split('\n')[0]}`); // 行号从 1 计（含 version 行）
  }
  return shader;
}
```

- 注意：`#version 300 es` 必须第一行——模板字符串拼前缀多一个换行就中招。

**程序链接**：编译、链接、立即回收 shader。

```typescript
export function createProgram(gl: GL, vsSource: string, fsSource: string): WebGLProgram {
  const vs = compileShader(gl, gl.VERTEX_SHADER, vsSource);
  const fs = compileShader(gl, gl.FRAGMENT_SHADER, fsSource);
  const program = gl.createProgram()!;
  gl.attachShader(program, vs); gl.attachShader(program, fs); gl.linkProgram(program);
  gl.deleteShader(vs); gl.deleteShader(fs); // 链接成功后源码已并入，立即释放
  if (!gl.getProgramParameter(program, gl.LINK_STATUS)) {
    const log = gl.getProgramInfoLog(program) ?? '(无日志)'; gl.deleteProgram(program);
    throw new Error(`program link failed: ${log}`); // 顶点 out 与片元 in 对不上是头号原因
  }
  return program;
}
```

**uniform 快速设置器**：location 缓存包装，null 也缓存。

```typescript
export class Uniforms {
  private cache = new Map<string, WebGLUniformLocation | null>();
  constructor(private gl: GL, private program: WebGLProgram) {}
  private loc(name: string): WebGLUniformLocation | null { // null 一并缓存：拼错的名字不必每帧再查
    if (!this.cache.has(name)) this.cache.set(name, this.gl.getUniformLocation(this.program, name));
    return this.cache.get(name)!;
  }
  f(name: string, ...v: number[]) { // 1~4 个 float
    const l = this.loc(name);
    if (!l) return;
    if (v.length === 1) this.gl.uniform1f(l, v[0]);
    else if (v.length === 2) this.gl.uniform2f(l, v[0], v[1]);
    else if (v.length === 3) this.gl.uniform3f(l, v[0], v[1], v[2]); else this.gl.uniform4f(l, v[0], v[1], v[2], v[3]);
  }
  int(name: string, v: number) { const l = this.loc(name); if (l) this.gl.uniform1i(l, v); }
  mat4(name: string, m: Float32Array) { // transpose 规范要求恒 false
    const l = this.loc(name); if (l) this.gl.uniformMatrix4fv(l, false, m);
  }
}
```

- 注意：location 为 null 时 uniform 调用是静默 no-op（[01 卡 1.7](01-WebGL-API速查.md)，sampler 的"绑纹理 + 传单元号"也在那张表）；GLSL 源码变了要重建 program 与缓存。

## 3.3 几何上传

交错与索引绘制详解：[几何与索引绘制 1.1](../02-第二阶段/02-几何与索引绘制.md)；VAO 省了什么：[WebGL2 特性 6.1](../02-第二阶段/07-WebGL2特性.md)。

**交错 buffer 上传**：pos(3)+uv(2)+normal(3) 拼进一个 VBO（uvs/normals 传空数组表示没有）。

```typescript
export interface InterleavedLayout { stride: number; attribs: Array<{ name: string; size: number; offset: number }> }

export function uploadInterleaved(gl: GL, positions: Float32Array, uvs: Float32Array, normals: Float32Array) {
  const n = positions.length / 3; // 顶点数
  const hasUv = uvs.length === n * 2, hasN = normals.length === n * 3;
  const stride = (3 + (hasUv ? 2 : 0) + (hasN ? 3 : 0)) * 4; // 字节步长
  const data = new Float32Array(n * stride / 4);
  let o = 0;
  for (let i = 0; i < n; i++) {
    data.set(positions.subarray(i * 3, i * 3 + 3), o); o += 3;
    if (hasUv) { data.set(uvs.subarray(i * 2, i * 2 + 2), o); o += 2; }
    if (hasN) { data.set(normals.subarray(i * 3, i * 3 + 3), o); o += 3; }
  }
  const buffer = gl.createBuffer()!; gl.bindBuffer(gl.ARRAY_BUFFER, buffer); gl.bufferData(gl.ARRAY_BUFFER, data, gl.STATIC_DRAW);
  const attribs: InterleavedLayout['attribs'] = [{ name: 'aPosition', size: 3, offset: 0 }];
  if (hasUv) attribs.push({ name: 'aUv', size: 2, offset: 12 });
  if (hasN) attribs.push({ name: 'aNormal', size: 3, offset: hasUv ? 20 : 12 });
  return { buffer, count: n, layout: { stride, attribs } };
}
```

- 注意：一个交错 VBO 优于多个 VBO（一次上传、访存局部性好）；usage 九格表见 [01 卡 1.3](01-WebGL-API速查.md)。

**attribute 布置 + VAO 建立**：WebGL2 核心，WebGL1 自动走扩展。

```typescript
type AnyVAO = WebGLVertexArrayObject | WebGLVertexArrayObjectOES | null;

export function bindAttribs(gl: GL, program: WebGLProgram, layout: InterleavedLayout,
                            vertexBuffer: WebGLBuffer, indexBuffer?: WebGLBuffer): void {
  // 无 VAO 时的兜底路径：WebGL1 每次绘制前手动调用
  gl.bindBuffer(gl.ARRAY_BUFFER, vertexBuffer);
  for (const a of layout.attribs) {
    const loc = gl.getAttribLocation(program, a.name);
    if (loc < 0) continue; // 着色器没用到的属性：跳过，不算错
    gl.enableVertexAttribArray(loc); gl.vertexAttribPointer(loc, a.size, gl.FLOAT, false, layout.stride, a.offset);
  }
  if (indexBuffer) gl.bindBuffer(gl.ELEMENT_ARRAY_BUFFER, indexBuffer);
}
export function createVAO(gl: GL, program: WebGLProgram, layout: InterleavedLayout,
                          vertexBuffer: WebGLBuffer, indexBuffer?: WebGLBuffer): AnyVAO {
  const record = () => bindAttribs(gl, program, layout, vertexBuffer, indexBuffer);
  if ('createVertexArray' in gl) { // WebGL2：录制后解绑
    const gl2 = gl as WebGL2RenderingContext, vao = gl2.createVertexArray();
    gl2.bindVertexArray(vao); record(); gl2.bindVertexArray(null);
    return vao;
  }
  const ext = gl.getExtension('OES_vertex_array_object');
  if (!ext) return null; // 老设备无扩展：绘制前手动调 bindAttribs()
  const vao = ext.createVertexArrayOES();
  ext.bindVertexArrayOES(vao); record(); ext.bindVertexArrayOES(null);
  return vao;
}
```

- 注意：VAO 连 ELEMENT_ARRAY_BUFFER 绑定也记录（WebGL2 行为）；几何被多个 program 复用时要各建 VAO，或在 GLSL 写死 layout(location)。

**索引绘制模板（双版本）**：

```typescript
// WebGL2：状态都在 VAO 里，绘制就两行
export function drawIndexed(gl: WebGL2RenderingContext, program: WebGLProgram,
                            vao: WebGLVertexArrayObject, indexCount: number): void {
  gl.useProgram(program); gl.bindVertexArray(vao);
  gl.drawElements(gl.TRIANGLES, indexCount, gl.UNSIGNED_SHORT, 0); // count 是索引个数
}
// WebGL1（或无 VAO 扩展）：绘制前手动布置 attribute
export function drawIndexedNoVAO(gl: GL, program: WebGLProgram, layout: InterleavedLayout,
                                 vertexBuffer: WebGLBuffer, indexBuffer: WebGLBuffer,
                                 indexCount: number): void {
  gl.useProgram(program);
  bindAttribs(gl, program, layout, vertexBuffer, indexBuffer); // 复用 bindAttribs，再画
  gl.drawElements(gl.TRIANGLES, indexCount, gl.UNSIGNED_SHORT, 0);
}
```

- 注意：`UNSIGNED_SHORT` 对应 Uint16Array（顶点数 ≤ 65535）；更多顶点用 `UNSIGNED_INT`（WebGL2 或 `OES_element_index_uint`）。

## 3.4 纹理工具

纹理基础：[纹理](../02-第二阶段/03-纹理.md)；canvas 文本：[文本与 2D 渲染 2.2](../技术专题/02-文本与2D渲染.md)；天空盒：[雾效与天空盒 5.2](../05-第五阶段/06-雾效与天空盒.md)。

**图片 → 纹理**：占位素 + 异步加载 + mipmap。

```typescript
export function createTextureFromImage(gl: GL, src: string) {
  const texture = gl.createTexture()!;
  gl.bindTexture(gl.TEXTURE_2D, texture); // 1x1 黑占位：ready 前采样也有定义
  gl.texImage2D(gl.TEXTURE_2D, 0, gl.RGBA, 1, 1, 0, gl.RGBA,
                gl.UNSIGNED_BYTE, new Uint8Array([0, 0, 0, 255]));
  const ready = new Promise<void>((resolve, reject) => {
    const img = new Image(); img.crossOrigin = 'anonymous'; // 跨域图不设它，读回时 SECURITY_ERR
    img.onload = () => {
      gl.bindTexture(gl.TEXTURE_2D, texture);
      gl.pixelStorei(gl.UNPACK_FLIP_Y_WEBGL, 1); // 图片 v 轴朝下，翻转对齐 UV 习惯
      gl.texImage2D(gl.TEXTURE_2D, 0, gl.RGBA, gl.RGBA, gl.UNSIGNED_BYTE, img);
      gl.pixelStorei(gl.UNPACK_FLIP_Y_WEBGL, 0); // 成对还原，别影响后续上传
      gl.generateMipmap(gl.TEXTURE_2D);
      gl.texParameteri(gl.TEXTURE_2D, gl.TEXTURE_MIN_FILTER, gl.LINEAR_MIPMAP_LINEAR);
      gl.texParameteri(gl.TEXTURE_2D, gl.TEXTURE_MAG_FILTER, gl.LINEAR);
      gl.texParameteri(gl.TEXTURE_2D, gl.TEXTURE_WRAP_S, gl.CLAMP_TO_EDGE); gl.texParameteri(gl.TEXTURE_2D, gl.TEXTURE_WRAP_T, gl.CLAMP_TO_EDGE);
      resolve();
    };
    img.onerror = () => reject(new Error(`图片加载失败: ${src}`));
    img.src = src; });
  return { texture, ready };
}
```

- 注意：MIN_FILTER 用 mipmap 档就必须 generateMipmap，且 WebGL1 下纹理须 2 次幂（NPOT 限制见 [01 卡 1.4](01-WebGL-API速查.md)）。

**canvas → 纹理（动态更新）**：文字、HUD、2D 图层。

```typescript
export function createCanvasTexture(gl: GL, canvas: HTMLCanvasElement) {
  const texture = gl.createTexture()!;
  const upload = () => {
    gl.bindTexture(gl.TEXTURE_2D, texture);
    gl.texImage2D(gl.TEXTURE_2D, 0, gl.RGBA, gl.RGBA, gl.UNSIGNED_BYTE, canvas);
    gl.texParameteri(gl.TEXTURE_2D, gl.TEXTURE_MIN_FILTER, gl.LINEAR); // 动态纹理通常不配 mipmap
    gl.texParameteri(gl.TEXTURE_2D, gl.TEXTURE_MAG_FILTER, gl.LINEAR);
    gl.texParameteri(gl.TEXTURE_2D, gl.TEXTURE_WRAP_S, gl.CLAMP_TO_EDGE); gl.texParameteri(gl.TEXTURE_2D, gl.TEXTURE_WRAP_T, gl.CLAMP_TO_EDGE);
  };
  upload();
  return {
    texture,
    update: upload, // canvas 重画后手动调用，整块重传
    dispose() { gl.deleteTexture(texture); },
  };
}
```

- 注意：每帧重传整张 canvas 很贵，文本只在内容变化时 update()；canvas 分辨率按实际显示尺寸 ×DPR 建。

**cubemap 六面加载**：天空盒/环境反射。

```typescript
export function createCubemap(gl: GL, faceUrls: string[]): Promise<WebGLTexture> {
  // faceUrls 顺序固定：+X, -X, +Y, -Y, +Z, -Z
  return new Promise((resolve, reject) => {
    const texture = gl.createTexture()!;
    let remaining = 6;
    faceUrls.forEach((url, i) => {
      const img = new Image(); img.crossOrigin = 'anonymous';
      img.onload = () => {
        gl.bindTexture(gl.TEXTURE_CUBE_MAP, texture);
        gl.texImage2D(gl.TEXTURE_CUBE_MAP_POSITIVE_X + i, 0, gl.RGBA, // 枚举连续：POSITIVE_X + i
                      gl.RGBA, gl.UNSIGNED_BYTE, img);
        if (--remaining === 0) { // 六面全齐才能配置 + mipmap
          gl.generateMipmap(gl.TEXTURE_CUBE_MAP);
          gl.texParameteri(gl.TEXTURE_CUBE_MAP, gl.TEXTURE_MIN_FILTER, gl.LINEAR_MIPMAP_LINEAR);
          gl.texParameteri(gl.TEXTURE_CUBE_MAP, gl.TEXTURE_WRAP_S, gl.CLAMP_TO_EDGE); gl.texParameteri(gl.TEXTURE_CUBE_MAP, gl.TEXTURE_WRAP_T, gl.CLAMP_TO_EDGE);
          resolve(texture);
        }
      };
      img.onerror = () => reject(new Error(`cubemap 面加载失败: ${url}`));
      img.src = url; });
    });
  });
}
```

- 注意：六面尺寸必须一致且为 2 次幂（WebGL1），否则 mipmap/完整性出问题；采样方向约定见 [雾效与天空盒 5.2](../05-第五阶段/06-雾效与天空盒.md)。

```typescript
export function createDepthTexture(gl: WebGL2RenderingContext, w: number, h: number): WebGLTexture {
  const texture = gl.createTexture()!;
  gl.bindTexture(gl.TEXTURE_2D, texture);
  gl.texImage2D(gl.TEXTURE_2D, 0, gl.DEPTH_COMPONENT24, w, h, 0, gl.DEPTH_COMPONENT, gl.UNSIGNED_INT, null);
  gl.texParameteri(gl.TEXTURE_2D, gl.TEXTURE_MIN_FILTER, gl.NEAREST); gl.texParameteri(gl.TEXTURE_2D, gl.TEXTURE_MAG_FILTER, gl.NEAREST); // 深度不过滤

}
```

## 3.5 FBO 工具

原理详解：[帧缓冲与离屏渲染 5.2](../02-第二阶段/06-帧缓冲与离屏渲染.md)；ping-pong 范式：[后处理管线 2.1](../05-第五阶段/03-后处理管线.md)。

**完整 createFBO**：颜色纹理 + 可选深度，含完整性检查与 resize。

```typescript
export interface FBO {
  fbo: WebGLFramebuffer; color: WebGLTexture; depth: WebGLRenderbuffer | null; width: number; height: number;
  resize(w: number, h: number): void; bind(): void; dispose(): void;
}

export function createFBO(gl: GL, width: number, height: number, withDepth = true): FBO {
  const fbo = gl.createFramebuffer()!;
  const color = gl.createTexture()!;
  const depth = withDepth ? gl.createRenderbuffer()! : null;
  const setup = (w: number, h: number) => {
    gl.bindFramebuffer(gl.FRAMEBUFFER, fbo);
    gl.bindTexture(gl.TEXTURE_2D, color);
    gl.texImage2D(gl.TEXTURE_2D, 0, gl.RGBA, w, h, 0, gl.RGBA, gl.UNSIGNED_BYTE, null);
    gl.texParameteri(gl.TEXTURE_2D, gl.TEXTURE_MIN_FILTER, gl.LINEAR); gl.texParameteri(gl.TEXTURE_2D, gl.TEXTURE_MAG_FILTER, gl.LINEAR);
    gl.texParameteri(gl.TEXTURE_2D, gl.TEXTURE_WRAP_S, gl.CLAMP_TO_EDGE); gl.texParameteri(gl.TEXTURE_2D, gl.TEXTURE_WRAP_T, gl.CLAMP_TO_EDGE);
    gl.framebufferTexture2D(gl.FRAMEBUFFER, gl.COLOR_ATTACHMENT0, gl.TEXTURE_2D, color, 0);
    if (depth) {
      gl.bindRenderbuffer(gl.RENDERBUFFER, depth);
      gl.renderbufferStorage(gl.RENDERBUFFER, gl.DEPTH_COMPONENT16, w, h);
      gl.framebufferRenderbuffer(gl.FRAMEBUFFER, gl.DEPTH_ATTACHMENT, gl.RENDERBUFFER, depth);
    }
    const status = gl.checkFramebufferStatus(gl.FRAMEBUFFER); // 不查这步，之后所有 draw 全失效
    if (status !== gl.FRAMEBUFFER_COMPLETE) throw new Error(`FBO 不完整: 0x${status.toString(16)}`);
    gl.bindFramebuffer(gl.FRAMEBUFFER, null);
  };
  setup(width, height);
  return {
    fbo, color, depth, width, height,
    resize(w, h) { this.width = w; this.height = h; setup(w, h); }, // 重新分配颜色与深度
    bind() { gl.bindFramebuffer(gl.FRAMEBUFFER, fbo); }, // 绑定后记得 viewport(0,0,w,h)
    dispose() {
      gl.deleteFramebuffer(fbo); gl.deleteTexture(color); if (depth) gl.deleteRenderbuffer(depth);
    },
  };
}
```

- 注意：绑定 FBO 后 viewport 不会跟着变，必须手动 `gl.viewport(0, 0, fbo.width, fbo.height)`——"只画出来左下角一块"的老牌坑；深度附件要被采样（shadow map）就换 3.4 深度纹理。

**ping-pong 对**：双 FBO 交替读写。

```typescript
export class PingPong {
  private fbos: [FBO, FBO];
  private index = 0;
  constructor(gl: GL, width: number, height: number, withDepth = false) {
    this.fbos = [createFBO(gl, width, height, withDepth), createFBO(gl, width, height, withDepth)];
  }
  get write(): FBO { return this.fbos[this.index]; }    // 本轮渲染目标
  get read(): FBO { return this.fbos[1 - this.index]; } // 上轮结果，作输入纹理
  swap(): void { this.index = 1 - this.index; }         // 每帧末尾调一次
  resize(w: number, h: number): void { this.fbos.forEach((f) => f.resize(w, h)); }
  dispose(): void { this.fbos.forEach((f) => f.dispose()); }
}
```

- 注意：帧序是"bind write → 把 read.color 当纹理画进 write → swap"；GPGPU 的通用封装见 [GPGPU 与计算 3.2](../技术专题/03-GPGPU与计算.md)。

## 3.6 相机工具

**perspective / lookAt（列主序）**：

```typescript
export function perspective(fovyRad: number, aspect: number, near: number, far: number): Float32Array {
  const f = 1 / Math.tan(fovyRad / 2), nf = 1 / (near - far);
  return new Float32Array([ // 列主序：每一行是一个"列"
    f / aspect, 0, 0, 0,  0, f, 0, 0,
    0, 0, (far + near) * nf, -1,  0, 0, 2 * far * near * nf, 0,
  ]);
}
export function lookAt(eye: readonly number[], center: readonly number[], up: readonly number[]): Float32Array {
  // z = eye→center 反向（相机看 -z）；x = up×z（右）；y = z×x（上）
  const z = normalize3([eye[0] - center[0], eye[1] - center[1], eye[2] - center[2]]);
  const x = normalize3(cross3(up, z)), y = cross3(z, x);
  return new Float32Array([
    x[0], y[0], z[0], 0,  x[1], y[1], z[1], 0,  x[2], y[2], z[2], 0,
    -(x[0] * eye[0] + x[1] * eye[1] + x[2] * eye[2]),
    -(y[0] * eye[0] + y[1] * eye[1] + y[2] * eye[2]),
    -(z[0] * eye[0] + z[1] * eye[1] + z[2] * eye[2]), 1,
  ]);
}
function cross3(a: readonly number[], b: readonly number[]): number[] { // 叉积
  return [a[1] * b[2] - a[2] * b[1], a[2] * b[0] - a[0] * b[2], a[0] * b[1] - a[1] * b[0]];
}
function normalize3(v: readonly number[]): number[] {
  const len = Math.hypot(v[0], v[1], v[2]) || 1;
  return [v[0] / len, v[1] / len, v[2] / len];
}
```

- 注意：fovy 传弧度（`90 * Math.PI / 180`）；up 与视线平行时 cross 退化（lookAt 著名坑）；正式项目用 [minmath](../03-第三阶段/02-数学库minmath.md) 同名函数。

**屏幕坐标 → 世界射线（完整五步）**：

```typescript
export interface Ray { origin: number[]; direction: number[] }

export function screenToWorldRay(clientX: number, clientY: number, canvas: HTMLCanvasElement,
                                 viewMatrix: Float32Array, projMatrix: Float32Array,
                                 camPos: readonly number[]): Ray {
  const rect = canvas.getBoundingClientRect();
  const px = clientX - rect.left, py = clientY - rect.top; // 1. client → canvas 相对像素
  const ndcX = (px / rect.width) * 2 - 1;                  // 2. → NDC，y 翻转（鼠标向下为正）
  const ndcY = -((py / rect.height) * 2 - 1);
  // 3. 近/远平面两个 NDC 点（z=-1 近，z=1 远）
  const invVP = invert4x4(multiply4x4(projMatrix, viewMatrix)); // 4. 逆(VP) 变回世界空间
  const near = transformPoint4(invVP, [ndcX, ndcY, -1, 1]);    //    并做透视除法
  const far = transformPoint4(invVP, [ndcX, ndcY, 1, 1]);
  return { // 5. 射线 = 近点 → 远点方向
    origin: [...camPos],
    direction: normalize3([far[0] - near[0], far[1] - near[1], far[2] - near[2]]),
  };
}

// 三个矩阵小工具（完整版在第一阶段数学模块：05-图形学数学基础"完整代码"节）
function multiply4x4(a: ArrayLike<number>, b: ArrayLike<number>): Float32Array {
  const out = new Float32Array(16);
  for (let c = 0; c < 4; c++) for (let r = 0; r < 4; r++) {
    out[c * 4 + r] = a[r] * b[c * 4] + a[4 + r] * b[c * 4 + 1]
                   + a[8 + r] * b[c * 4 + 2] + a[12 + r] * b[c * 4 + 3];
  }
  return out;
}
function transformPoint4(m: ArrayLike<number>, p: readonly number[]): number[] {
  const [x, y, z, w] = p;
  const ow = m[3] * x + m[7] * y + m[11] * z + m[15] * w; // 透视除法
  return [
    (m[0] * x + m[4] * y + m[8] * z + m[12] * w) / ow,
    (m[1] * x + m[5] * y + m[9] * z + m[13] * w) / ow,
    (m[2] * x + m[6] * y + m[10] * z + m[14] * w) / ow, ow,
  ];
}
function invert4x4(m: ArrayLike<number>): Float32Array { // 伴随矩阵法（gl-matrix 同款）
  const b00 = m[0]*m[5]-m[1]*m[4],    b01 = m[0]*m[6]-m[2]*m[4],    b02 = m[0]*m[7]-m[3]*m[4];
  const b03 = m[1]*m[6]-m[2]*m[5],    b04 = m[1]*m[7]-m[3]*m[5],    b05 = m[2]*m[7]-m[3]*m[6];
  const b06 = m[8]*m[13]-m[9]*m[12],  b07 = m[8]*m[14]-m[10]*m[12], b08 = m[8]*m[15]-m[11]*m[12];
  const b09 = m[9]*m[14]-m[10]*m[13], b10 = m[9]*m[15]-m[11]*m[13], b11 = m[10]*m[15]-m[11]*m[14];
  let det = b00 * b11 - b01 * b10 + b02 * b09 + b03 * b08 - b04 * b07 + b05 * b06;
  if (!det) return new Float32Array(16); // 不可逆返回零矩阵，调用方自查
  det = 1 / det;
  return new Float32Array([
    (m[5]*b11 - m[6]*b10 + m[7]*b09) * det,    (m[2]*b10 - m[1]*b11 - m[3]*b09) * det,
    (m[13]*b05 - m[14]*b04 + m[15]*b03) * det, (m[10]*b04 - m[9]*b05 - m[11]*b03) * det,
    (m[6]*b08 - m[4]*b11 - m[7]*b07) * det,    (m[0]*b11 - m[2]*b08 + m[3]*b07) * det,
    (m[14]*b02 - m[12]*b05 - m[15]*b01) * det, (m[8]*b05 - m[10]*b02 + m[11]*b01) * det,
    (m[4]*b10 - m[5]*b08 + m[7]*b06) * det,    (m[1]*b08 - m[0]*b10 - m[3]*b06) * det,
    (m[12]*b04 - m[13]*b02 + m[15]*b00) * det, (m[9]*b02 - m[8]*b04 - m[11]*b00) * det,
    (m[5]*b07 - m[4]*b09 - m[6]*b06) * det,    (m[0]*b09 - m[1]*b07 + m[2]*b06) * det,
    (m[13]*b01 - m[12]*b03 - m[14]*b00) * det, (m[8]*b03 - m[9]*b01 + m[10]*b00) * det,
  ]);
}
```

- 注意：canvas 被缩放时用 `rect.width` 而不是 `canvas.width` 归一（第 2 步已按 rect 算）；射线与三角形/包围盒求交在 [交互系统 4.2/4.3](../04-第四阶段/05-交互系统.md)。

```typescript
export function createDrawCallCounter(gl: GL) {
  let count = 0;
  const proxy = new Proxy(gl, {
    get(target, prop) {
      const value = Reflect.get(target, prop, target);
      if (typeof value === 'function' && String(prop).startsWith('draw')) { // draw* 全计数
        count++; return (value as (...args: unknown[]) => unknown).bind(target);
      }
      return value;
    },
  }) as GL;
  return {
    gl: proxy, // 业务代码拿这个 gl 用，其余行为不变
    get count() { return count; }, reset() { count = 0; }, // 每帧开头 reset，帧尾读 count
  };
}
```

```typescript
export function makeGLErrorChecker(gl: GL) {
  const names: Record<number, string> = {
    [gl.INVALID_ENUM]: 'INVALID_ENUM', [gl.INVALID_VALUE]: 'INVALID_VALUE',
    [gl.INVALID_OPERATION]: 'INVALID_OPERATION', // 当前状态不允许的操作（最常见）
    [gl.OUT_OF_MEMORY]: 'OUT_OF_MEMORY', [gl.CONTEXT_LOST_WEBGL]: 'CONTEXT_LOST_WEBGL',
  };
  return function checkGL(label = ''): boolean {
    let e = gl.getError(); const ok = e === gl.NO_ERROR;
    while (e !== gl.NO_ERROR) { // 错误排队存储，必须循环取空
      console.error(`[GL] ${label} ${names[e] ?? `0x${e.toString(16)}`}`); e = gl.getError();
    }
    return ok;
  };
}
```

**FPS 表 + frame time 移动平均**：每秒结算 + 滑动窗口。

```typescript
export class FpsMeter {
  private frames = 0;
  private last = performance.now();
  fps = 0;
  tick(now = performance.now()): number {
    this.frames++;
    if (now - this.last >= 1000) { // 满 1 秒结算，帧内零开销
      this.fps = (this.frames * 1000) / (now - this.last);
      this.frames = 0; this.last = now;
    }
    return this.fps;
  }
}
export class FrameTimeAverage {
  private buf: number[] = [];
  constructor(private windowSize = 60) {}
  push(dtMs: number): number {
    this.buf.push(dtMs); if (this.buf.length > this.windowSize) this.buf.shift();
    const sum = this.buf.reduce((a, b) => a + b, 0);
    return sum / this.buf.length; // 返回滑动平均帧耗时（ms）
  }
}
```

- 注意：平均会抹平尖刺，排查卡顿还要看单帧最大值；配合 3.7 的 drawcall 计数能快速回答"这帧贵在提交量还是 GPU"。

**requestIdleCallback 资源预热**：首帧前把重活摊进空闲。

```typescript
type IdleCallback = (deadline: IdleDeadline) => void;
const scheduleIdle: (cb: IdleCallback, opts?: IdleRequestOptions) => number =
  typeof requestIdleCallback === 'function'
    ? (cb, opts) => requestIdleCallback(cb, opts)
    : (cb) => window.setTimeout(() => cb({ didTimeout: false, timeRemaining: () => 4 }), 1); // 降级

export function warmupWhenIdle(tasks: Array<() => void>, timeoutMs = 3000): void {
  let i = 0;
  const step = (deadline: IdleDeadline) => {
    while (i < tasks.length && deadline.timeRemaining() > 1) tasks[i++](); // 每片只吃空闲时间
    if (i < tasks.length) scheduleIdle(step, { timeout: timeoutMs });
  };
  if (tasks.length > 0) scheduleIdle(step, { timeout: timeoutMs });
}
```

- 注意：预热"编译着色器、上传纹理"这类一次性任务，真机空闲回调可能迟迟不来，timeout 兜底保证跑完；用法是把 `createProgram`、`createTextureFromImage` 包成任务数组交给它，首次交互就没有编译卡顿。
