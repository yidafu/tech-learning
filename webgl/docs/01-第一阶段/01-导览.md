# 第一阶段导览：渲染管线与 WebGL 入门

> [返回：WebGL 与 3D 框架学习大纲](../WebGL与3D框架学习大纲.md)
> 本文是第一阶段的入口：阶段目标、分册索引、阅读路线、实践任务清单与阶段自测；建议开阶段时读一遍定计划，收阶段时再读一遍查漏。

**建议时长**：2~3 周（每天 1~2 小时）。环境要求只要一个新版浏览器（Chrome / Edge / Firefox / Safari 任一）和 F12 控制台，全程零依赖、零安装；本阶段所有示例都是单 HTML 文件，双击即可运行（`file://` 协议足够，第二阶段用到纹理时再考虑本地服务器）。

## 阶段目标

学完本阶段，你应该能不查资料做到这些事：

1. 讲清一次 `drawArrays` 从 JS 调用到屏幕像素点亮，中间经历了哪几个阶段、每个阶段由谁执行、哪些可编程。
2. 独立写出一个完整可运行的 WebGL 程序（HTML + 着色器 + VBO），并在着色器编译失败时靠日志定位到行。
3. 读懂并会写常用 GLSL：类型、限定符（attribute / uniform / varying 与 WebGL2 的 in / out）、内置变量、精度、swizzle。
4. 手推平移 / 旋转 / 缩放矩阵，手写 lookAt 与透视投影矩阵，讲清"局部 → 世界 → 相机 → 裁剪 → NDC → 屏幕"六个坐标空间的全链路。
5. 结业实践：不借助任何库，画一个自转 + 公转的立方体，数学函数全部手写。

本阶段的两个产出物会在后面反复复用：一套手写数学函数（第三阶段 minmath 数学库的种子）和一套"着色器编译 + 错误日志"的模板代码（之后每个 demo 都从它起步）。

## 实践任务清单

"看懂"不算数，跑起来才算（与大纲用法一致；每完成一项回大纲勾选）。

- [ ] 任务 0（环境）：跑通 03 册 2.2 的三角形 HTML；打开 F12 确认控制台无报错。
- [ ] 任务 1：修改三角形的顶点坐标与颜色，加三个顶点用一次 `drawArrays` 画两个拼成四边形的三角形。
- [ ] 任务 2：故意写坏着色器（删分号、删 precision、拼错 varying 名各试一次），对照 03 册 2.3 的排查表看懂每一类报错。
- [ ] 任务 3：改 04 册的片元着色器，用 `step` / `mix` 做出条纹或棋盘格效果（练习分量式运算替代 if）。
- [ ] 任务 4：把 05 册的 TypeScript 数学模块跑起来（`npx tsx` 或去类型贴浏览器控制台），三条断言全过。
- [ ] 任务 5（结业）：完成 06 册的自转 + 公转立方体，满足验收标准六条（见 06 册开头）。
- [ ] 选做：给 06 册的立方体加第二个"卫星"立方体（绕行星再公转），体会矩阵链的嵌套——这其实就是第三阶段场景图的雏形。

## 阶段自测

做完上面任务后回答（口述或笔记均可）；括号指向对应分册，答不上的回去重读。

2. 为什么片元着色器里不能声明 attribute？一次画 3 个顶点、覆盖 50 万像素的三角形，顶点/片元着色器各执行多少次？（02 册 1.4）
3. WebGL2 相比 WebGL1 至少列出三条实质差异；本仓库"上下文双保险 + 着色器以 ES 1.00 为主线"的取舍理由是什么？（02 册 1.3）
4. attribute、uniform、varying 的数据来源、更新频率与作用范围各是什么？WebGL2 里分别对应什么写法？（04 册 3.1）
5. 片元着色器为什么必须显式声明 float 精度？mediump 用在大世界坐标上会出什么问题？（04 册 3.3）
6. 点积和叉积各举两个图形学用途；为什么"用点积求夹角"之前必须先归一化？（05 册 4.1）

8. 透视除法发生在哪两个阶段之间？除掉的 w 是从哪来的？（05 册 4.4、4.5）
