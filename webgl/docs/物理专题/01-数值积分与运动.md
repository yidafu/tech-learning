## 1.1 游戏物理的简化设定

### 概念：质点、刚体，以及"要不要转动"

物理引擎对"物体"有三档抽象，成本差一个量级：

| 模型 | 状态量 | 自由度 | 能做什么 | 代价 |
|---|---|---|---|---|
| 质点（point mass） | 位置、速度 | 3 | 弹跳、下落、随风飘 | 最低 |
| 平动刚体（无自转） | + 形状（球/盒）、质量、摩擦/弹性 | 3 | 弹跳、堆叠、触发器、射线查询 | 低 |
| 全刚体（rigid body） | + 姿态（四元数）、角速度、惯性张量（inertia tensor） | 6 | 滚动、倾倒、力矩、摩擦生转 | 高 |

全刚体的"贵"在三处：姿态要按角速度积分四元数（dq/dt = ½·ω·q，推导在 [数学专题/03-旋转表示与转换](../数学专题/03-旋转表示与转换.md)）；惯性张量是 3×3 矩阵且随姿态变换（I_world = R·I_local·Rᵀ）；摩擦会生力矩，角速度与线速度耦合求解。

**本专题的最小集取中间档：平动刚体。** 球和盒有大小、有质量、有摩擦弹性，但不自转——损失是"滚动的球会滑不会滚、塔倒了不会翻转"，换来的是整条链路（积分、检测、响应）都能手算验证。需要旋转时：装饰性的滚动可以用速度配一个美术旋转（在渲染节点上转，不进物理）；真的需要力矩与惯性，就去 [02](02-碰撞检测与响应.md) 2.7 换 cannon-es/rapier。2D 还是 3D？本专题代码全 3D，但多数演示把运动约束在竖直平面内——2D 物理没有更简单，只是少一个轴。

### 概念：固定时间步（fixed timestep）——为什么渲染帧率不该驱动物理

第三阶段 RenderLoop（[03-第三阶段/03-引擎最小核心](../03-第三阶段/03-引擎最小核心.md)）预告过结论：渲染、相机阻尼用可变步长，物理必须固定步长。理由四条：

1. **稳定性**：积分误差与步长直接相关（1.2 会看到能量误差是 dt 的函数）。渲染帧率波动 → dt 忽大忽小 → 同一根弹簧时软时硬，大 dt 直接数值爆炸；
2. **确定性**：固定 dt + 相同输入 = 相同结果。可变 dt 下 60Hz 屏与 144Hz 屏算出不同轨迹——单元测试、回放、联机同步全部失效；
3. **帧率解耦**：掉帧时物理"慢放"（少跑几个固定步），而不是每步迈一大截穿越场景；120Hz 屏不会让重力凭空变强；
4. **约束求解的前提**：1.3 的 Verlet 与迭代约束都隐含"步长恒定"，变步长会破坏位置差的语义。

方案是 **accumulator（累积器）模式**：每渲染帧把真实流逝的时间攒进累积器，攒够一个固定步长就执行一次物理步，渲染时对"上一物理状态 → 当前物理状态"插值。

### 数值手算：90Hz 渲染 + 60Hz 物理时的 alpha 序列

渲染帧约 11.11ms，物理步 16.67ms，累积器的消耗过程：

```text
帧 1：acc = 11.11        不足一步，物理不动；alpha = 11.11/16.67 = 0.667
帧 2：acc = 22.22 → 走 1 步，剩 5.56；alpha = 0.333
帧 3：acc = 16.67 → 走 1 步，剩 0.00；alpha = 0.000
帧 4：acc = 11.11        周期重复：0.667 → 0.333 → 0.000 → …
```

每 3 个渲染帧恰好消耗 2 个物理步（3×11.11 = 2×16.67）。不插值直接渲染当前状态，物体位置只在帧 2、3 更新——90Hz 的屏幕上运动以 60Hz 跳动，肉眼可见"微抖/卡顿感"；用 alpha 插值后每个渲染帧都有唯一位置，平滑。

### 完整代码：accumulator 骨架

```typescript
// physics/fixedStep.ts —— accumulator 模式骨架（1.4 的 PhysicsLoop 是它的工程化版本）
export interface AccumulatorState {
  time: number; // 剩余时间（秒）
}

/**
 * 每渲染帧调用一次：攒真实时间、按固定步消耗。
 * 返回 alpha ∈ [0, 1)：当前渲染帧落在两个物理状态之间的比例，供插值。
 */
export function runWithFixedStep(
  frameDt: number,          // 本渲染帧时长（已被 RenderLoop clamp，见第三阶段 maxDelta = 0.1）
  fixedDt: number,          // 固定物理步长，如 1/60
  state: AccumulatorState,
  step: (dt: number) => void,
): number {
  state.time += frameDt;
  let steps = 0;
  const maxSteps = 5; // 保险丝：物理比渲染慢时最多补 5 步，防止"死亡螺旋"（见常见坑 1）
  while (state.time >= fixedDt && steps < maxSteps) {
    step(fixedDt);
    state.time -= fixedDt;
    steps++;
  }
  if (steps === maxSteps) state.time = 0; // 追不上就丢弃积压：宁可慢放，不能雪崩
  return state.time / fixedDt;
}
```

用法（插值的存状态时机在 step 回调开头，顺序错了等于没存）：

```typescript
const accState: AccumulatorState = { time: 0 };
const alpha = runWithFixedStep(delta, 1 / 60, accState, (h) => {
  for (const b of bodies) {
    b.px = b.x; b.py = b.y; b.pz = b.z;   // ① 先把"当前"存成"上一状态"
  }
  integrateAll(h);                         // ② 再积分到新状态
});
for (const b of bodies) {
  b.node.position.set(                     // ③ 渲染状态 = lerp(prev, curr, alpha)
    b.px + (b.x - b.px) * alpha,
    b.py + (b.y - b.py) * alpha,
    b.pz + (b.z - b.pz) * alpha,
  );
}
```

## 1.2 数值积分三法

### 概念：积分器是在解常微分方程

牛顿第二定律 F = ma 是二阶常微分方程（ODE）：位置对时间求两次导等于加速度。数值积分把它拆成两个一阶问题：dv/dt = F/m、dx/dt = v，然后一步步离散推进。游戏里只有三种积分器值得认识：

- **显式欧拉（explicit Euler）**：位置、速度都用"旧值"推进；
- **半隐式欧拉（semi-implicit Euler，又称辛欧拉 symplectic Euler）**：先更新速度，再用**新**速度更新位置；
- **Verlet 积分（Verlet integration）**：不存速度，存上一帧位置，速度隐含在位置差里。

三者代码都不超过十行，差别全在**稳定性**——同一个弹簧，一个越弹越大，两个永远有界。

### 推导：三个更新公式

**显式欧拉**：把 v(t) 在 t 处泰勒展开取一阶：v(t+dt) ≈ v(t) + a(t)·dt，x 同理：

```text
x' = x + v·dt          （v 是旧速度）
v' = v + (F/m)·dt      （F 是旧位置/旧速度算出的力）
```

**半隐式欧拉**：只调换两行的顺序——速度先走一步，位置用新速度：

```text
v' = v + (F/m)·dt
x' = x + v'·dt         （v' 是新速度）
```

**Verlet**：对 x(t+dt) 与 x(t−dt) 泰勒展开后相加，二阶项保留、奇次项抵消：

```text
x(t+dt) = x + v·dt + ½a·dt² + …
x(t−dt) = x − v·dt + ½a·dt² − …
两式相加：x(t+dt) = 2x − x(t−dt) + a·dt²   ← 更新只用到加速度，速度不出现
隐式速度：v ≈ (x(t+dt) − x(t)) / dt
```

带阻尼的工程形式（位置差乘阻尼系数 damping ∈ [0.95, 1)）：

```text
x' = x + (x − x_prev)·damping + a·dt²
```

### 推导与数值手算：弹簧为什么会数值爆炸

标准试金石是无阻尼弹簧振子：x'' = −(k/m)·x，角频率 ω = √(k/m)，精确解 x(t) = x₀·cos(ωt)。取 k = 100、m = 1（ω = 10 rad/s），x₀ = 1、v₀ = 0，能量 E = ½v² + ½kx²，初值 E₀ = 50。

**显式欧拉每步把能量乘以 (1 + ω²dt²)。** 把更新式代入能量定义：

```text
x' = x + v·dt,  v' = v − ω²x·dt
v'²     = v² − 2ω²xv·dt + ω⁴x²dt²
ω²x'²   = ω²x² + 2ω²xv·dt + ω²v²dt²
相加：交叉项抵消 → v'² + ω²x'² = (v² + ω²x²)(1 + ω²dt²)
即 E' = E·(1 + ω²dt²)
```

能量按固定比例放大、与初值无关——显式欧拉对振荡系统**无条件不稳定**。矩阵视角更直观：状态 (x, v) 的推进矩阵行列式 det = 1 + ω²dt² > 1（相空间面积每步放大），而半隐式欧拉的推进矩阵 det 恰为 1（保面积，这正是"辛/保辛"的含义），特征值落在单位圆上，能量误差有界振荡。

**手算一（显式欧拉爆炸，dt = 0.25）**：ω·dt = 2.5，每步能量 ×7.25。

```text
步 1：x₁ = 1 + 0·0.25 = 1        v₁ = 0 − 100·1·0.25 = −25
步 2：x₂ = 1 + (−25)·0.25 = −5.25   v₂ = −25 − 100·1·0.25 = −50
步 3：x₃ = −5.25 + (−50)·0.25 = −17.75
      v₃ = −50 − 100·(−5.25)·0.25 = 81.25
E₃ = ½(81.25² + 100·17.75²) ≈ 19054 = 50×7.25³   ← 与公式互证：3 步放大 381 倍
```

**手算二（三法对比，dt = 1/60，ω·dt ≈ 0.167 < 2）**：

| 步 n | 精确 cos(10·n·dt) | 显式欧拉 | 半隐式欧拉 | Verlet |
|---|---|---|---|---|
| 1 | 0.98614 | 1.00000 | 0.97222 | 0.98611 |
| 2 | 0.94496 | 0.97222 | 0.91744 | 0.94483 |
| 3 | 0.87758 | 0.91667 | 0.83717 | 0.87767 |
| 趋势 | — | 相位滞后且能量渐增 | 相位略超前、能量有界 | 几乎重合 |

半隐式欧拉与 Verlet 的稳定条件都是 **ω·dt ≤ 2**（把更新式代入特征方程可得：Verlet 的特征方程 λ² − (2 − ω²dt²)λ + 1 = 0，判据 |2 − ω²dt²| ≤ 2）。这就是**步长与刚度的关系**：

$$dt \le \frac{2}{\omega} = 2\sqrt{\frac{m}{k}}$$

刚度 k 涨一百倍，稳定步长要缩小十倍（√k 关系）。"硬弹簧逼着小步长"是所有力式模拟的痛，1.3 的位置式方法正是为此而生。若某个约束必须很硬，用 substep：按 ω·dt ≤ 2 把一步切成 n = ⌈dt·ω/2⌉ 个子步。

### 完整代码：三个积分器

```typescript
// physics/integrators.ts —— 三种积分器（作用于质点；invMass = 0 的静态体跳过）
export interface Particle {
  x: number; y: number; z: number;      // 位置
  vx: number; vy: number; vz: number;   // 速度
  invMass: number;                      // 逆质量 1/m（静态体为 0；永远用它，别写 1/mass）
  fx: number; fy: number; fz: number;   // 本步累积的力（每步清零，见 1.4）
}

/** 显式欧拉：位置、速度都用旧值——最直观，但振荡系统能量越积越多 */
export function integrateExplicit(p: Particle, dt: number): void {
  if (p.invMass === 0) return;
  p.x += p.vx * dt;
  p.y += p.vy * dt;
  p.z += p.vz * dt;
  p.vx += p.fx * p.invMass * dt;
  p.vy += p.fy * p.invMass * dt;
  p.vz += p.fz * p.invMass * dt;
}

/** 半隐式欧拉（symplectic Euler）：先速度后位置——游戏物理的默认选择 */
export function integrateSemiImplicit(p: Particle, dt: number): void {
  if (p.invMass === 0) return;
  p.vx += p.fx * p.invMass * dt;
  p.vy += p.fy * p.invMass * dt;
  p.vz += p.fz * p.invMass * dt;
  p.x += p.vx * dt;
  p.y += p.vy * dt;
  p.z += p.vz * dt;
}

/** Verlet 质点：不存速度，存上一帧位置 */
export interface VerletParticle {
  x: number; y: number; z: number;
  px: number; py: number; pz: number;   // 上一帧位置
  invMass: number;
  ax: number; ay: number; az: number;   // 本步加速度（力/质量，或力场直接给）
}

/** Störmer–Verlet：x' = x + (x − x_prev)·damping + a·dt² */
export function integrateVerlet(p: VerletParticle, dt: number, damping = 0.995): void {
  if (p.invMass === 0) { p.px = p.x; p.py = p.y; p.pz = p.z; return; }
  const vx = (p.x - p.px) * damping;    // 阻尼作用于隐式速度
  const vy = (p.y - p.py) * damping;
  const vz = (p.z - p.pz) * damping;
  p.px = p.x; p.py = p.y; p.pz = p.z;
  p.x += vx + p.ax * dt * dt;
  p.y += vy + p.ay * dt * dt;
  p.z += vz + p.az * dt * dt;
}
```

弹簧对比台（接上表，可直接跑）：

```typescript
// springDemo.ts —— 弹簧振子对比台：x'' = −(k/m)x，k = 100、m = 1 → ω = 10
const k = 100, m = 1, dt = 1 / 60, x0 = 1, v0 = 0;   // E₀ = 50

export function springDemo(steps = 180): void {
  let xE = x0, vE = v0;                       // 显式欧拉
  let xS = x0, vS = v0;                       // 半隐式欧拉
  const a0 = -(k / m) * x0;                   // Verlet 用 x₋₁ 自举：x₋₁ = x₀ − v₀dt + ½a₀dt²
  let xV = x0, xVprev = x0 - v0 * dt + 0.5 * a0 * dt * dt;
  for (let n = 0; n < steps; n++) {
    const xE2 = xE + vE * dt;                 // 显式：都用旧值
    vE = vE - (k / m) * xE * dt;
    xE = xE2;
    vS = vS - (k / m) * xS * dt;              // 半隐式：先速度后位置
    xS = xS + vS * dt;
    const xV2 = 2 * xV - xVprev - (k / m) * dt * dt * xV;  // Verlet
    xVprev = xV;
    xV = xV2;
  }
  const t = steps * dt;
  console.log("精确:", Math.cos(10 * t), "| 显式:", xE, "| 半隐式:", xS, "| Verlet:", xV);
  // t = 3s 时精确 cos(30) ≈ 0.155；显式欧拉的振幅早已按 (1.0278)^n 涨飞
}
```

结论与分工：**平动刚体世界用半隐式欧拉**（速度显式可查，02 篇的冲量要直接改速度）；**布料/绳索/粒子用 Verlet**（约束投影只需要位置，见 1.3）。

## 1.3 Verlet 与约束

### 概念：从"力式"到"位置式"

把绳结成一个环、把弹簧刚度调到 1e6，力式模拟（弹簧胡克定律 F = −k·Δx）会逼你用极小步长（1.2 的 ω·dt ≤ 2）。Verlet 带来另一条路：**约束直接投影位置**——检测到违反（两点距离 ≠ 静止长度），就把两点**直接挪到**满足约束的位置，不解力、不解速度。这套思想叫基于位置的动力学（position-based dynamics，PBD）：速度隐含在位置差里，位置被修正后，下一帧的位置差自动成为新速度，"被拉扯过的地方自然慢下来"。

### 推导：距离约束的投影求解

约束 C(p₁, p₂) = |p₁ − p₂| − rest = 0。修正量 Δ 沿连线方向，按**逆质量**分配（逆质量 w = 1/m，静态点 w = 0）：

```text
dir = (p₂ − p₁) / |p₂ − p₁|        err = |p₂ − p₁| − rest
p₁ += dir·err·w₁/(w₁ + w₂)         p₂ −= dir·err·w₂/(w₁ + w₂)
```

按逆质量分配不是随手——它保持质心不动（动量守恒的离散版）。**手算验证**：m₁ = 1（w₁ = 1）、m₂ = 3（w₂ = 1/3），rest = 2，当前 p₁ = (0,0,0)、p₂ = (3,0,0)：

```text
err = 3 − 2 = 1（沿 +x）；w₁ + w₂ = 4/3
p₁ += 1·(3/4)·(1,0,0) = (0.75, 0, 0)      p₂ −= 1·(1/4)·(1,0,0) = (2.75, 0, 0)
检查：新距离 = 2.75 − 0.75 = 2 = rest，约束满足；
质心：前 (0·1 + 3·3)/4 = 2.25；后 (0.75 + 3·2.75)/4 = 2.25，不变（轻的挪得多，重的挪得少）
```

多个约束（布料的横竖网）不联立求解，而是**顺序投影（Gauss–Seidel 式）**：从头到尾修一遍所有约束，修后面时会把前面稍微拉坏一点，那就再修一遍——重复 N 次直到收敛。每遍 O(约束数)，无矩阵、无求逆。

### 完整代码：布料模拟（PBD 最小版）

```typescript
// physics/Cloth.ts —— Verlet + 距离约束的布料最小版
// 渲染端：positions() 写进网格顶点 buffer（或直接当 GL_LINES 端点画骨架）
export interface ClothParticle {
  x: number; y: number; z: number;
  px: number; py: number; pz: number;  // 上一帧位置（Verlet）
  invMass: number;                     // 钉住的粒子为 0
}

export interface DistanceConstraint {
  a: number; b: number;   // 粒子下标
  rest: number;           // 静止长度
}

export class Cloth {
  readonly particles: ClothParticle[] = [];
  readonly constraints: DistanceConstraint[] = [];
  gravityY = -9.81;
  windStrength = 1.5;      // 风力（加速度量纲，单位质量的力）
  damping = 0.985;

  constructor(
    readonly cols: number,      // 横向粒子数
    readonly rows: number,      // 纵向粒子数
    readonly spacing: number,   // 相邻粒子间距（米）
    readonly iterations = 4,    // 约束投影遍数：越多布料越"硬"（见下文权衡）
  ) {
    // ① 粒子网格：顶部一排钉住（invMass = 0），布料从 y = 0 向下挂
    for (let r = 0; r < rows; r++) {
      for (let c = 0; c < cols; c++) {
        this.particles.push({
          x: c * spacing, y: -r * spacing, z: 0,
          px: c * spacing, py: -r * spacing, pz: 0,
          invMass: r === 0 ? 0 : 1,
        });
      }
    }
    // ② 结构约束：横向相邻 + 纵向相邻各一条（剪切/弯曲约束是扩展项）
    for (let r = 0; r < rows; r++) {
      for (let c = 0; c < cols; c++) {
        const i = r * cols + c;
        if (c + 1 < cols) this.constraints.push({ a: i, b: i + 1, rest: spacing });
        if (r + 1 < rows) this.constraints.push({ a: i, b: i + cols, rest: spacing });
      }
    }
  }

  step(dt: number, t: number): void {
    this.integrate(dt, t);
    for (let i = 0; i < this.iterations; i++) this.satisfyConstraints();
    this.collideGround(0);
  }

  /** Verlet 积分：重力 + 阵风（随时间与粒子起伏，布料才有"飘"感） */
  private integrate(dt: number, t: number): void {
    const dtSq = dt * dt;
    for (let i = 0; i < this.particles.length; i++) {
      const p = this.particles[i];
      if (p.invMass === 0) continue;
      const gust = this.windStrength * (0.6 + 0.4 * Math.sin(t * 2.3 + i * 0.37));
      const vx = (p.x - p.px) * this.damping;
      const vy = (p.y - p.py) * this.damping;
      const vz = (p.z - p.pz) * this.damping;
      p.px = p.x; p.py = p.y; p.pz = p.z;
      p.x += vx;
      p.y += vy + this.gravityY * dtSq;
      p.z += vz + gust * dtSq;
    }
  }

  /** 距离约束投影：顺序修所有约束，重复 iterations 遍 */
  private satisfyConstraints(): void {
    const ps = this.particles;
    for (const c of this.constraints) {
      const p1 = ps[c.a], p2 = ps[c.b];
      let dx = p2.x - p1.x, dy = p2.y - p1.y, dz = p2.z - p1.z;
      const dist = Math.sqrt(dx * dx + dy * dy + dz * dz);
      if (dist < 1e-9) continue;                  // 两点重合：方向未定义，跳过（NaN 防御）
      const wSum = p1.invMass + p2.invMass;
      if (wSum === 0) continue;                   // 两端都钉死：不用修
      const err = (dist - c.rest) / dist / wSum;  // 每单位逆质量的修正系数
      dx *= err; dy *= err; dz *= err;
      p1.x += dx * p1.invMass; p1.y += dy * p1.invMass; p1.z += dz * p1.invMass;
      p2.x -= dx * p2.invMass; p2.y -= dy * p2.invMass; p2.z -= dz * p2.invMass;
    }
  }

  /** 地面碰撞：位置钳制 + 借"上一位置"实现切向摩擦与法向非弹性 */
  private collideGround(groundY: number): void {
    for (const p of this.particles) {
      if (p.invMass === 0 || p.y >= groundY) continue;
      p.x = p.px + (p.x - p.px) * 0.5;   // 切向：上一位置拉近 → 隐式速度打对折 = 摩擦
      p.z = p.pz + (p.z - p.pz) * 0.5;
      p.y = groundY; p.py = groundY;     // 法向：prev 与当前同值 → 隐式速度归零 = 非弹性
    }
  }

  /** 输出粒子世界坐标（写顶点 buffer；面片法线随后重算） */
  positions(): Float32Array {
    const out = new Float32Array(this.particles.length * 3);
    for (let i = 0; i < this.particles.length; i++) {
      out[i * 3] = this.particles[i].x;
      out[i * 3 + 1] = this.particles[i].y;
      out[i * 3 + 2] = this.particles[i].z;
    }
    return out;
  }
}
```

### 迭代次数与刚度的权衡

| iterations | 手感 | 每步成本 |
|---|---|---|
| 1 | 明显拉伸的"橡皮布" | O(C) |
| 3–4 | 日常布料/旗帜 | O(C) |
| 8–12 | 偏硬的皮革 | O(C)×3 倍 |
| 20+ | 接近刚性，开始与固定 dt"顶牛"（高频抖动） | CPU 吃紧 |

理论上，若每遍只修 k ∈ (0,1] 比例的误差，N 遍后残余 (1−k)ᴺ——有效刚度 1−(1−k)ᴺ 随迭代次数指数收敛，这就是"迭代次数换刚度"：力式里"刚度逼小步长"（1.2），位置式里换成"刚度逼迭代次数"，而迭代次数是纯性能旋钮，不影响稳定性。代价：约束多时 CPU 线性变贵，且迭代内误差往复传播，布料太硬 + dt 太大仍会抖——极限处与 1.2 的稳定边界殊途同归。

## 1.4 落地：PhysicsLoop 接口设计

### 概念：step / interpolate 两阶段

框架的物理模块对外只有一个循环类 PhysicsLoop，两阶段方法：

- **step(dt)**：内部被 accumulator 以固定步长驱动，做"存上一状态 → 积分（02 篇再加检测/响应）"；
- **interpolate()**：渲染前调用，按 alpha 把插值状态写进绑定的场景节点。

渲染层只见 interpolate 的输出，物理内部换积分器、加碰撞、甚至换引擎（2.7），都不影响外面的 RenderLoop。

### 完整代码：PhysicsLoop 与 ParticleWorld

```typescript
// physics/PhysicsLoop.ts —— 固定步循环骨架：step / interpolate 两阶段
export abstract class PhysicsLoop {
  private accumulator = 0;

  constructor(
    readonly fixedDt = 1 / 60,        // 固定步长；堆叠/硬布料建议 1/120
    private readonly maxSubSteps = 5, // 死亡螺旋保险丝
  ) {}

  /** 每渲染帧调用一次（喂 RenderLoop 的 delta） */
  update(frameDt: number): void {
    this.accumulator += frameDt;
    let steps = 0;
    while (this.accumulator >= this.fixedDt && steps < this.maxSubSteps) {
      this.savePrevState();            // ① 存上一物理状态（顺序：先存后积分）
      this.step(this.fixedDt);         // ② 前进一个固定步
      this.accumulator -= this.fixedDt;
      steps++;
    }
    if (steps === this.maxSubSteps) this.accumulator = 0;
  }

  /** 渲染前调用：把插值状态写到绑定的场景节点 */
  interpolate(): void {
    this.applyInterpolated(this.accumulator / this.fixedDt);  // alpha ∈ [0, 1)
  }

  protected abstract savePrevState(): void;
  protected abstract step(dt: number): void;
  protected abstract applyInterpolated(alpha: number): void;
}
```

```typescript
// physics/ParticleWorld.ts —— 力/冲量 API（02 篇的 RigidBodyWorld 在此扩展）
/** 力场：按"单位质量的力"（加速度）返回，重力就是一个内建力场 */
export type AccelField = (
  body: RigidBody, timeSec: number,
) => { x: number; y: number; z: number };

export class RigidBody {
  x = 0; y = 0; z = 0;               // 位置（当前物理状态）
  px = 0; py = 0; pz = 0;            // 位置（上一物理状态，供插值）
  vx = 0; vy = 0; vz = 0;
  fx = 0; fy = 0; fz = 0;            // 力累加器（每步清零）
  invMass = 1;
  boundNode: { position: { x: number; y: number; z: number } } | null = null;

  addForce(fx: number, fy: number, fz: number): void {      // 持续力：作用于本步
    this.fx += fx; this.fy += fy; this.fz += fz;
  }
  addImpulse(ix: number, iy: number, iz: number): void {    // 瞬时冲量：直接改速度
    this.vx += ix * this.invMass;
    this.vy += iy * this.invMass;
    this.vz += iz * this.invMass;
  }
}

export class ParticleWorld extends PhysicsLoop {
  readonly bodies: RigidBody[] = [];
  gravity = { x: 0, y: -9.81, z: 0 };  // 全局重力（加速度量纲）
  linearDrag = 0;                      // 线性阻力系数 c：F = −c·v
  private fields: AccelField[] = [];   // 风、浮力、局部场……
  private time = 0;

  add(body: RigidBody, node?: RigidBody["boundNode"]): RigidBody {
    body.boundNode = node ?? null;
    this.bodies.push(body);
    return body;
  }

  addField(f: AccelField): void { this.fields.push(f); }

  protected savePrevState(): void {
    for (const b of this.bodies) { b.px = b.x; b.py = b.y; b.pz = b.z; }
  }

  protected step(dt: number): void {
    this.time += dt;
    for (const b of this.bodies) {
      if (b.invMass === 0) continue;
      // ① 合加速度 = 重力 + 力场 + addForce 累加的力
      let ax = this.gravity.x + b.fx * b.invMass;
      let ay = this.gravity.y + b.fy * b.invMass;
      let az = this.gravity.z + b.fz * b.invMass;
      for (const f of this.fields) {
        const v = f(b, this.time);
        ax += v.x; ay += v.y; az += v.z;
      }
      // ② 半隐式欧拉：先速度（阻力以速度衰减因子实现，等价 F = −c·v 的离散）
      const damp = 1 - this.linearDrag * b.invMass * dt;
      b.vx = b.vx * damp + ax * dt;
      b.vy = b.vy * damp + ay * dt;
      b.vz = b.vz * damp + az * dt;
      // ③ 再位置
      b.x += b.vx * dt;
      b.y += b.vy * dt;
      b.z += b.vz * dt;
      // ④ 力累加器清零：addForce 的语义是"作用于这一步"
      b.fx = 0; b.fy = 0; b.fz = 0;
    }
  }

  protected applyInterpolated(alpha: number): void {
    for (const b of this.bodies) {
      if (!b.boundNode) continue;
      b.boundNode.position.x = b.px + (b.x - b.px) * alpha;
      b.boundNode.position.y = b.py + (b.y - b.py) * alpha;
      b.boundNode.position.z = b.pz + (b.z - b.pz) * alpha;
    }
  }
}
```

两条接入纪律：**插值必须在 updateMatrixWorld 之前**（写完位置才轮到场景图算世界矩阵，与动画系统的 mix → updateMatrixWorld → draw 铁律同一条流水线，见 [04-第四阶段/06-动画系统](../04-第四阶段/06-动画系统.md) 开篇的帧顺序图）；**一个节点的变换只有一个写入者**——物理驱动的节点不挂动画轨道，动画驱动的节点不绑物理体，否则两者互相覆盖位置，表现为"半帧物理半帧动画的抽搐"。

阻力参数的手感标定（**手算**）：linearDrag = 1.2、m = 1、dt = 1/60 → 每步速度乘 1 − 1.2/60 = 0.98，每秒乘 0.98⁶⁰ ≈ 0.30——速度每秒衰减到三成。约束：c·invMass·dt 必须小于 2，否则衰减因子为负，速度每步翻转放大（常见坑 5）。

## 常见坑

1. **大步长爆炸与"死亡螺旋"**：后台标签页切回时单帧 delta 可达数秒（第三阶段 RenderLoop 已 clamp 到 0.1s，物理侧还要 maxSubSteps 兜底）。若物理一步耗时超过 fixedDt，accumulator 越攒越多、每帧补步越来越多——指数恶化直到页面卡死。保险丝断开（steps 达上限）就清空积压：**宁可慢放，不能雪崩**。另一个来源是刚度：k 变百倍，稳定 dt 缩十倍（1.2 的 √k 关系），上 substep 或换 1.3 的位置式；
2. **NaN 传播**：典型源头——normalize 零向量（约束两点重合）、力场回调返回 NaN、速度溢出到 Infinity 再参与运算。NaN 不会自愈，且随约束与接触**逐步污染邻居**（布料一个点炸，三帧后整块消失）。防御三层：除法前查分母（1.3 代码里的 `dist < 1e-9 continue`）；step 末抽检 `Number.isFinite(b.x)`，失败就隔离/重置该 body；力场入口钳制取值域。这与 GLSL 侧"pow 负底数返回 NaN 继续扩散"是同一条纪律——入口钳制输入域（[着色器语言专题/04-精度与编译器行为](../着色器语言专题/04-精度与编译器行为.md) 4.5 的未定义行为清单），CPU 侧多一层 isFinite 兜底；调试期的 NaN 定位思路见 [工程专题/01-调试与诊断](../工程专题/01-调试与诊断.md)；
3. **插值用错状态**：忘了存 prev（症状：高刷屏上物体微抖）；或 prev 存在 step 之后——那就等于 curr，插值永远输出 curr，白做。顺序铁律：**prev = curr 在前，积分在后**；
4. **Verlet 换步长**：位置差 (x − x_prev) 的语义绑定 dt，中途改 dt 等于给所有粒子一个速度突变。要么全程固定步长（本专题默认），要么上 time-corrected Verlet：x' = x + (x − x_prev)·(dt/dt_prev) + a·dt²；
5. **阻力过猛反向发散**：damp = 1 − c·invMass·dt ≥ 1（即 c·invMass·dt ≥ 2，含负号翻转）时速度每步反向放大。阻力参数按"每秒衰减到几成"标定（1.4 的手算），不要凭感觉加大；
6. **布料不对称拉伸**：Gauss–Seidel 顺序遍历让先修的约束占便宜，布料被单向拉歪。缓解：每遍交替遍历方向（偶数遍正序、奇数遍逆序），或把 iterations 拆成两半分方向跑。
